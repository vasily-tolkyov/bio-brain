# 第 2 段：脉冲网络

状态：部分完成。快照日期：2026-10-09。集成分支：`stage/2-spiking-network`。

## 目标

吸引子和有向通道在脉冲网络里由学习涌现，并能保持状态、沿通道演化；后两项是闭环里做模拟所需要的。

## 完成判据

- 已达成：`verify/L4-network.mjs`、`verify/L4-emergence.mjs` 的验证。
- 已在 v2 实验达成的学习基础：八组组内 / 全体组间平均 ρ 为 8.22–9.11；G=1 补全 +6.84 Hz、8/8 为正；选定 G_learn=0.6 后补全 +1.82 Hz、8/8 为正，静息点燃率 2.67%。代码与数值保存在 `attempt/2/attractor-chain-v2`。
- 未验证的保持与收尾：终点线索撤掉后，至少 80% 的试次保持 ≥ 80 ms，至少 80% 的停留在 1 s 内结束；激活频率 15–80 Hz，演化态静息点燃率 ≤ 10%。
- 未全部达成的方向学习：v2 经两次补救后，七条正向减反向 ρ、实际计数 Spearman、分叉排序、吸引子与静息指标通过；最好的平均方向差为 0.04376，仍低于 0.05，因此停止后续模拟。
- 未验证的自主链条：40 个有效试次完成率 ≥ 50%、链长中位数 ≥ 4、正向比例 ≥ 70%、反向比例 ≤ 10%；C→D/C→G 各 ≥ 3 次，分叉比 1.5–9；停留均值 40–400 ms、CV ≥ 0.3。
- 没学序列、打乱顺序、无适应、低噪声四项对照均需通过；v2 另外要求记录原规则对照 5e。完整条件见[v2 尝试记录](attempts/attractor-chain-v2.md)，解码定义沿用[第一版记录](attempts/attractor-chain.md)。

## 现状

### 速率网络

补全 0.997–0.999；能量只降不升，没有伪吸引子。序列 0→…→5 需要不对称连接加疲劳。这些权重按公式计算，并非学得。

### 脉冲网络 L4b

100 个兴奋性细胞与 25 个抑制性细胞；09529fe 的涌现结果，解码见 74be198：

- 补全从 0% 到 50%。
- 维持原型所需的驱动 17.5 → 13.1 Hz，体现能量极小。
- 组内 / 组间 ρ 为 0.40 / 0.16；相邻组正向 / 反向 ρ 为 0.410 / 0.062。
- 持续驱动一组时，下一组 / 上一组被拉起 10.0 / 0.1 Hz。

平衡层为 400 + 100：自发 3.0 Hz，反应分级；补全 +0.8 Hz；通道相对对照组 B 为 +2.9 Hz；A→D 0.31、D→A 0.20。

### 不自持、不会自主演化

2026-10-05 做过一次只读时间进程测试：载入训练缓存，给 A 一段输入后撤掉，按 10 ms 分箱记录。当时为一次性运行，没有保存脚本。

- 旧网络：给 A 40 ms，A、B、D 在 10–20 ms 的同一分箱里一起爆发，分别为 67.5 / 75.5 / 51 Hz；20 ms 后整层归零，撤掉输入后一直为 0。
- 平衡层：给 A 40 ms，A 在撤掉后 20–30 ms 掉到 2.7 Hz，之后到 250 ms 一直低于自发，为 1.6–2.8 Hz（静息 3.4）。D 在 A 期间和之后约 80 ms 为 4–5 Hz（静息 3.0）；对照 B 被压到 0.1–1.1 Hz。
- 通道让下一组在当前组被驱动时被顺带拉起或免于被压，尚未形成状态转移。

递归放大 1.3–1.4 倍、不再平衡的上层能自持，但切断纠正时静息有 29–32% 的时间自己点燃，新输入来了也不让位。低频持续活动仍是[技术说明](../../../README.zh-CN.md)“已知缺口”第 1 条。

### 有向通道演化链尝试：步骤 1 失败

2026-10-09，720 个兴奋性与 180 个快速抑制性细胞，八组各 80 个成员，训练 300 次含噪变体。背景按计划允许的范围从 E=28 Hz 调为 30 Hz，I=12 Hz；训练前 E/I=2.075/5.433 Hz、Fano=1.770，达标。

训练后，八组组内 / 组间比为 0.973–1.831，全部低于 2；补全平均 +0.347 Hz，6/8 组为正，低于 +0.5 Hz 与至少七组的要求。静息点燃率为 0%，但吸引子选择性和补全未通过，因此按停止条件没有进入序列、演化标定、链条或对照。共享 src 和原有 48 个缓存均未改动，FAST 回归通过。实验代码、数值、图与日志归档到 `attempt/2/attractor-chain`；本分支只接收记录与 STATUS 更新。

### 有向通道演化链 v2：规则与吸引子通过，方向强度不足

2026-10-09，以同一网络规模重做。新增可选 GB_RATE，抑制原规则在静息与零星巧合下的非特异增强；L3 配对、L4 逐拍对拍和九项网络规则测试通过。兴奋递归仅在刺激期学习，组内连接加密为 0.25、组间为 0.083；学习增益同步缩放可塑上下限。两个获准的 src 文件有改动，原规则逐位一致检查及 FAST 回归通过。

300 次变体后，八组选择性为 8.22–9.11，补全 +6.84 Hz、8/8 为正。G=1 静息点燃 62.67%；六点标定选出最大可用 G_learn=0.6，静息点燃 2.67%，补全 +1.82 Hz、8/8 为正。

S2 在 160×40 ms、续算 320×40 ms、从吸引子重训 320×30 ms 下，平均方向差分别为 0.02950、0.04376、0.03093，均低于 0.05。后两次的七条方向差均 ≥0.02，分叉 C→D>C→G、Spearman、前七大连接、吸引子及静息条件通过；但两次补救已用尽，故未运行演化标定、自主链或对照。完整结果与图见[尝试记录](attempts/attractor-chain-v2.md)，代码、数据和运行日志归档到 `attempt/2/attractor-chain-v2`；本分支接收记录与缓存说明。

完整回归用时 2684 s：原有十组检查及新增 L4h 通过，L4g 因 S2 门槛不足和后续未运行而失败，总退出码为 1。原有 50 个缓存的 SHA-256 全部保持不变。本次按部分成功路径结束。

## 复现

在仓库根目录执行：

```powershell
node verify/L4-network.mjs
node verify/L4-emergence.mjs
node demo/fig2-network.mjs
node demo/fig5-decode.mjs
node demo/balanced-layer.mjs
```

`L4-emergence` 约 4 分钟；平衡层需要 `bal-1-s9-e0.02.json`，没有时先训练约 9 分钟。缓存对应关系见 [CACHE.md](../../CACHE.md)。

v2 在[实验标签](https://github.com/vasily-tolkyov/bio-brain/tree/attempt/2/attractor-chain-v2)的独立工作区执行：`node verify/L4-rate-rule.mjs`，再以 `MODE=all` 运行 `node demo/attractor-chain.mjs`。后者按阶段门槛运行，S2 两次补救失败时退出 2；`node verify/L4-chain.mjs` 会以退出 1 逐条报告失败与未运行项。完整 `npm run verify` 的归档结果见尝试记录。
