# 第 2 段：脉冲网络

状态：部分完成。快照日期：2026-10-06。集成分支：`stage/2-spiking-network`。

## 目标

吸引子和有向通道在脉冲网络里由学习涌现，并能保持状态、沿通道演化；后两项是闭环里做模拟所需要的。

## 完成判据

- 已达成：`verify/L4-network.mjs`、`verify/L4-emergence.mjs` 的验证。
- 草案，未达成：撤掉输入后吸引子以 10–50 Hz 维持至少 1 s，静息时不自燃。

## 现状

### 速率网络

补全 0.997–0.999；能量只降不升，没有伪吸引子。序列 0→…→5 需要不对称连接加疲劳。这些权重按公式计算，并非学得。

### 脉冲网络 L4b

100 个兴奋性细胞与 25 个抑制性细胞；09529fe 的涌现结果，解码见 74be198：

- 补全从 0% 到 50%。
- 维持原型所需的驱动 17.5 → 13.1 Hz，体现能量极小。
- 组内 / 组间 ρ 为 0.40 / 0.16；相邻组正向 / 反向 ρ 为 0.410 / 0.062。
- 持续驱动一组时，下一组 / 上一组被拉起 10.0 / 0.1 Hz。

平衡层为 400 + 100：自发 3.0 Hz，反应分级；补全 +0.8 Hz；通道相对对照组 B 为 +2.9 Hz；A→D 0.31、D→A 0.20。

### 不自持、不会自主演化

2026-10-05 做过一次只读时间进程测试：载入训练缓存，给 A 一段输入后撤掉，按 10 ms 分箱记录。当时为一次性运行，没有保存脚本。

- 旧网络：给 A 40 ms，A、B、D 在 10–20 ms 的同一分箱里一起爆发，分别为 67.5 / 75.5 / 51 Hz；20 ms 后整层归零，撤掉输入后一直为 0。
- 平衡层：给 A 40 ms，A 在撤掉后 20–30 ms 掉到 2.7 Hz，之后到 250 ms 一直低于自发，为 1.6–2.8 Hz（静息 3.4）。D 在 A 期间和之后约 80 ms 为 4–5 Hz（静息 3.0）；对照 B 被压到 0.1–1.1 Hz。
- 通道让下一组在当前组被驱动时被顺带拉起或免于被压，尚未形成状态转移。

递归放大 1.3–1.4 倍、不再平衡的上层能自持，但切断纠正时静息有 29–32% 的时间自己点燃，新输入来了也不让位。低频持续活动仍是[技术说明](../../../README.zh-CN.md)“已知缺口”第 1 条。
