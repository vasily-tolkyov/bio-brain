# 顶树突反馈

- 状态：部分成功。
- 代码：`attempt/4/apical-feedback`（9b1e505，2026-10-02）。

## 目标与假设

把反馈放到顶树突，检查能否保持上传证据干净，并让预测进入正在感知的第一层。

## 做法

兴奋性神经元增加顶树突分区，包含钙平台与反传动作电位；反馈全部落在顶树突上，与点神经元版比较。

## 结果

- 第 3、4 层的物体通道 X→Y / Y→X 分别为 0.24 / 0.04、0.21 / 0.07；点神经元版为 0.07 / 0.11、0.07 / 0.16，方向反了。
- 第一层不变性回到 0.55；想象时第一层为 10.9 Hz。
- X 出现后，第一层 Y 组的顶树突约高 3 mV，约 20 ms 后退回；Y 的首个脉冲没有提前，为 31.1 / 31.1 ms。

## 结论与原因

上传证据变干净了，但预测仍传不到正在感知的第一层。瓶颈在发送端：第二层自己的 Y 预测也在与当前 X 竞争。
