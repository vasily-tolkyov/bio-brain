# 两层预测编码

- 状态：成功（里程碑）。
- 代码：`milestone/predictive-coding`（b501089，2026-10-03）。

## 目标与假设

分开表征、误差和预测中继，让上层解释下层证据，避免预测直接加到证据群上的正反馈。

## 做法

每层包含表征群 E、误差群 N、预测中继群 S；比较完整网络、切断预测抑制、切断预测下行和切断误差上行。测试熟悉物体、缺失部分、没见过的组合及物体切换。

## 结果

- 熟悉 X：头 25 ms 的误差 14.5 Hz，之后 3.4 Hz（自发 3.5）。
- 切断预测抑制 / 切断预测下行：39.3 / 33.5 Hz。
- 只给 A 时，缺失的 D 为 1.2 Hz。
- 没见过的 A + C：A、C 9.4 Hz，B、D 0.9 Hz。
- 误差群四组合计 12.0 Hz，切断预测时为 106.5。
- X 换成 Y 后头 50 ms，Y 的误差 17.0 Hz，切断误差上行时为 31.4。

## 结论与原因

分群后，物体级预测能解释掉熟悉输入的误差，误差上行参与修正上层状态。L4f 验证覆盖这些行为。
