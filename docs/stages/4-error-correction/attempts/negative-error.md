# 负误差细胞

- 状态：部分成功。
- 代码：`attempt/4/negative-error`（77a909c，2026-10-04）；选项 `pcNeg`。

## 目标与假设

用负误差细胞提供带符号的上行纠正，稳定加深上层，并让新输入能替换旧状态。

## 做法

上层递归放大 1.4 倍，比较“切断纠正 / 完整”条件；另检查仅用 NMDA 的纠正以及浅上层的表现。

## 结果

| 测量 | 切断纠正 | 完整 |
| --- | --- | --- |
| 上层自发 | 13.4–15.8 Hz | 3.4–3.5 Hz |
| X 撤掉后重新点燃 | 68–96 Hz | 0.9–1.2 Hz |
| 换成 Y 后 X 残留 | 59–69 Hz | 1.9–2.3 Hz |
| 换成 Y 后 Y 活动 | 142–148 Hz | 35–38 Hz |
| 静息时有组自己亮起来 | 29–32% | 17–24% |

纠正回路只用 NMDA 时失败，静息自燃 32.7%。同样的纠正放在浅上层偏强，熟悉 X 的正误差从 3.6 增至 8.6 Hz。

## 结论与原因

负误差显著减轻加深上层的重新点燃与旧状态残留，但没有解决静息自燃；纠正的动力学和强度仍需匹配。
