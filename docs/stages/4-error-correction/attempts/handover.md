# 加深上层的序列交接

- 状态：失败。
- 代码：`attempt/4/handover`（5134960，2026-10-04）。

## 目标与假设

结合加深上层、200 ms 痕迹与纠正，让上层在 X 后提前切换到 Y；检查适应能否减轻当前吸引子的竞争。

## 做法

比较上层增益、痕迹、纠正的切断，以及 40 / 60 / 100 pA 适应条件。

## 结果

- 加深 1.4 + 200 ms 痕迹 + 纠正：X→Y 0.15 → 0.20，Y→X 0.16 → 0.28，期待 −6.5 Hz。
- 不加痕迹：X→Y / Y→X 为 0.16 / 0.32，期待 −10.2 Hz。
- 切断纠正：0.27 / 0.29；物体内连接 0.42 → 0.31。
- 不加深 + 痕迹 + 纠正：0.20 / 0.13，方向正确，但期待为 −0.3 Hz。
- 加适应 40 / 60 / 100 pA：X→Y 0.24 / 0.20 / 0.14，Y→X 0.18 / 0.13 / 0.09；熟悉 X 时上层只剩 4.8 / 3.5 / 2.7 Hz（加深后原为 13.6）；期待为 1.2 / 0.5 / −1.3 Hz。
- 所有条件下，X 的最后 30 ms 上层 Y 都只有 0.1–0.5 Hz。

## 结论与原因

深的上层里当前吸引子放电很强，前一项的神经元零星放电。钙规则的同时检测项（突触前痕迹 × 突触后放电）因此学成 Y→X。浅时方向正确但表达不足；适应削弱当前活动，也未带来可靠期待。
