# 误差层面的序列期待

- 状态：在误差层面成功（里程碑）。
- 代码：`milestone/sequence-expectation`（586753a，2026-10-04）。

## 目标与假设

让 X→Y 的经验降低预期 Y 的误差，检查学习的时间窗口与预测中继动力学是否匹配。

## 做法

中继到误差的抑制性可塑性使用 200 ms 突触前痕迹，预测下行只用 NMDA；做痕迹与中继的 2×2 对照。

## 结果

- 起初没有学到期待：Y 的误差在 Y 出现后 10–25 ms 才冲高，此时 X 的中继已从 27 Hz 降到 7 Hz。
- 每经历一次 X→Y，20 ms 配对窗口的增减账为 −1.0；换成 200 ms 痕迹后为 +11.7（×10⁻³）。
- 2×2 对照按技术说明的顺序为 −0.1 / 0.3 / 2.0 / 8.3 Hz，痕迹与 NMDA-only 中继组合得到 8.3 Hz 的期待。
- X 的中继到 Y 的误差连接为 0.42 → 1.13；X 之后 Y 不来时，Y 的误差为 0.3 Hz（自发 3.0）。
- Y 的误差被推迟、压低，但没有消掉：10 ms 峰值为 28.1 Hz，反向为 42.8；X 末尾上层 Y 的组只有 0.2 Hz。

## 结论与原因

延长资格痕迹解决了先行输入与迟到误差的时间错配，慢中继保留预测。成功限于误差层面，上层没有提前换成 Y。
