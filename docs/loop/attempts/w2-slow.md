# W2 慢受体与完整状态导出

状态：通过。基线：W0、W5 合并后的 `stage/loop`。

## 目标与改动范围

在 `src/L4-network/spiking-network.mjs` 增加 `kind: 'slow'` 与完整 `exportState` / `importState`；新增 `verify/L4-slow.mjs`，`verify/all.mjs` 加入 L4i（FAST 也运行）。按本包实现段明确要求，将 `src/loop/e1.mjs` 的运行时工具改为调用完整状态接口。另保存本包记录及日志。

每组慢受体有自己的 τR / τD、电导状态；反转电位 0 mV、无镁阻断，按 AMPA 阳离子比例记 ATP。完整状态覆盖膜、适应、不应期、输入资源、全部受体与迹、各组资源 / z / ρ / scale、队列、随机数状态、账本及时间。

## 验收

1. 无慢受体时，与 W0 三种参考配置的放电与全部状态逐位相同，ATP 相对误差 ≤ 1e-12。
2. 单脉冲解析双指数：10/30 ms 与 9.2/18.5 s 两组各十个采样时刻，相对误差 ≤ 1e-6。
3. 同一批突触后神经元上两组不同动力学慢受体线性叠加，误差 ≤ 1e-9。
4. 慢电流 ATP 与按 AMPA 比例换算的积分电荷相同，相对误差 ≤ 1e-9。
5. 同时含慢受体、GB_RATE、抑制性可塑性的网络：1 s 导出 / JSON 导入再 1 s，与连续 2 s 逐位相同。额外覆盖顶树突、长抑制迹、组内 NMDA 迹和正态随机数缓存。
6. FAST 与完整 `npm run verify` 退出码均为 0。

不用慢受体时，不改变方程、加法或随机数调用的顺序。任何逐位失败、越出设计 / 范围或既有缓存变化，按计划归档并停止。长回归保存分组检查点。

慢受体会带来大量连接组；为仅修改权重的学习回调增加运行选项 `onStepWritesResources=false`，保留 W0 的稀疏资源恢复路径。默认行为保持不变。续算检查同时对照全数组与稀疏恢复，并包含外部预置的非 1 资源。首轮完整回归主动中断，保留已完成记录；在最终接口上重新执行完整回归，不将中断记为通过。

## 实测

全部验收通过。实现提交 `b581214`、`bed303a`；完整回归 13 组退出码 0，1637.184 s（27.3 min）；FAST 退出码 0，123 s。

三种无慢受体参考配置状态与放电逐位相同，ATP 相对误差为 0。两组解析电导的最大相对误差分别为 1.61e-14、1.71e-11；双组电导叠加误差为 0、ATP 叠加误差 1.99e-16；离散积分电荷换算 ATP 误差 3.53e-15。含 GB_RATE、ISTDP、慢受体、顶树突及正态随机数缓存的网络 JSON 续算逐位相同，导出 10,894 字节；E1 运行时工具完整往返也相同。
