## 验收

1. 四个场景各群规模和连接符合架构，保存表；不存在 E1/E2→P/Q。
2. 相同种子构建的连接哈希相同，换种子则不同。
3. 场景一完整网络和模块状态导出 / 导入后续跑 200 ms 逐位相同。
4. 每个场景静息 2 s 无 NaN：E1 2–5 Hz；E1 抑制群 5–20；N/M 2–5；C ≤2；L ≤0.5；P/D/U/E2 ≤5。
5. 原型共现更新符合手算；W 更新同步改写四条通路和余弦侧抑制。
6. FAST 回归退出码 0。

只允许背景在 E1 20–32 / I1 8–16、N 10–18、M 8–16、S/V 6–12、C/P/U/E2 0–20 Hz 范围内标定，每次取值和结果写 JSON。D 背景固定为 0。任何逐位失败、越出设计/范围或允许标定后仍未达标，按工程计划归档当前包、停止后续包。
