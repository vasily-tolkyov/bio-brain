## 步骤与验收

1. 改动前运行默认 E1（900 个神经元、学习打开）2 s 与 L4-emergence 使用的网络 2 s，记录每模拟 1 s 的墙钟耗时。
2. 保存 E1 学习 2 s、fig2-network 的 GB_NMDA 网络 1 s、predictive-hierarchy 网络 0.5 s 的放电与全部动态数组 SHA-256、ATP 分类账；`emergence` 同时纳入额外对照。
3. 用 `node --cpu-prof` 剖析后，只做保持运算顺序的优化。
4. 三种配置放电与状态逐位相同，ATP 各项相对误差不超过 1e-12；FAST 与完整 `npm run verify` 退出码均为 0。

逐位一致失败、既有缓存改变、需要越出设计或修改范围时，按工程计划第 2.3、6 节归档并停止。超过 30 分钟的回归保存分组检查点，未完成组从同一种子独立重跑。
