# W4-diag4 测量实现口径

固定网格与选择阈值原样执行。原始完整脉冲在每次检查点保留，电导只读采样在 traces/ 中，图使用已有测量，不重放网络。

- 两次水平检查均取连续3秒冻结静息；E2各另取10秒。点燃率按v2 restMetrics：20毫秒箱中任一E1特征组超过10 Hz的箱比例。影子L频率记录但不参与第一步的正式L水平门槛。
- D4训练前、D4训练后和D6顺序执行。基线分别使用最近一次3秒水平检查，不另加模拟。D4/D6每次刺激的实际开始、消失和间隔结束都保存在结果中。
- 机理静息段是两次3秒静息及D4前后所有试次的消失后300毫秒至下一次刺激开始；每个D4阶段的最后一次止于该次实际间隔结束，避免把训练阶段接进静息。N/M各特征都用同一组静息段。在场段只取该特征D6的开始后300毫秒至消失。
- 与探查脚本相同，机理计数按全局1毫秒箱取floor(脉冲时刻)，各分段端点取最近整数毫秒。Fano为样本方差/均值。5毫秒成团窗口逐毫秒扫描，命中后取随后10毫秒内的首个最大计数窗口，随后隔开20毫秒；保留全部事件时刻。
- E1台阶在训练后的D4十次及D6五次冻结试次上计算，出现/消失分子都取15次中的最小余量。分母窗口必须完全落在上述静息或在场段中，t步长2毫秒。M适应波、N反弹分别使用D4训练后的十次和规定的D6/静息基线。
- L装入使用完整脉冲历史，不在试次或分析段边缘重置50毫秒累加窗口及20毫秒间隔。出现/消失检出按装入时刻落在各自0–100毫秒窗口判断。方向对这些真实边界窗口内的装入逐次读出；无装入时正确率记0，同时检出失败。
- 在场与静息误装入以D4训练后的10次试次分别计比例。二次装入以20个变化机会计比例：同一次变化的首个装入之后，另一个装入落在50–150毫秒。D6保持以真实脉冲总数计算L频率，与训练后静息作max(0.3 Hz,3SE)比较。所有时间窗为半开区间，边界容差1e-8毫秒。
- N/M峰值和保持用20毫秒平均PSTH；S对比度用50–1000毫秒平均频率。残余上限参照同五次D6的边界PSTH峰值超出量；超阈比例限为静息超阈比例的2倍加1%。
- 动作A在动作期间保持世界脚本驱动。A→L的传出副本只在开始的50毫秒开放，之后关闭，避免持续动作反复装入；状态可精确保存，动作结束不产生额外装入信号。
- 场景四D8依次运行正常、N→E2置零、E1→E2置零三段10秒冻结静息。每段结束恢复原权重，三段之间不重置网络状态。
- 非有限网络量立即停止。分析中0/0或无穷比值明确记录为字符串，不用JSON隐式null代替；没有有效数值不能判通过。
