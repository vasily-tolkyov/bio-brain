## 0. 背景

### 机理探查（只读，不属于任何工作包）

做法：载入 diag3 训练后的状态（s1-t25-e4 的三个特征，另加 s1-t40-e4 的闪电），冻结学习，重放出现与消失，记录逐个脉冲和每毫秒的电导。脚本、输出与图在 `D:\kimi_kairos\bio-brain-wt\probe-mechanism\`，摘要见其中的 `probe-summary.md`。

1. **成团放电来自共用的小中继，不是 E1 在闪。**
   - 每个 N1 细胞接收全部 30 个 S1 细胞，每个 M1 细胞接收本组全部 10 个 V1 细胞；突触释放又是确定性的，同组误差细胞收到的抑制完全相同。
   - 中继偶尔一起安静 10–20 ms，全组误差细胞就同时放电：静息时每秒 2–4 次，在场时每秒 3–6 次。
   - E1 本身接近随机（法诺因子 1.2–2.2，没有节律）。
2. **E1 的适应造成反向的"第二波"。** 出现时 E1 先冲到 17–26 Hz，再在约 300 ms 内衰减到 7–11 Hz；于是出现后 100–300 ms，M1 升到在场后期的 2–2.3 倍，L⁻ 零星误触发。消失后 E1 低于静息 0.6–1 s，N1 随后回到或略高于静息。
3. **出现与消失不对称。** 在 E1 上做理想的台阶检测，出现是状态内最大波动的 1.9–2.2 倍，消失只有 1.0–1.2 倍。原因同样是适应压低了在场平台。
4. **L 是一个对同步敏感的单细胞。** 10 个 L 细胞参数相同、输入相同、没有背景，用 AMPA + NMDA。

### 设计修订（master 52227aa、4a3c223）

- **按特征的边界通道**（第 4.1、4.2、7.3、8、9 节）：
  - 每个特征只有一个 L、一组 C、一套 P/Q/Z/D/U；
  - N1_g、M1_g 都接到 L_g；
  - 方向不建通道，由装入时 E1_g 在不在场读出；
  - 动作只在开始时装入。
- **共享比例上限**（第 4.6 节）：通向 S1、V1、N1、M1、L 的前馈通路要求 k / n_pre ≤ 0.35，超过时截断 k，强度乘 k_ref / k。单元内部递归、E1 内部、E1 → I2 与误差上行不受限。
- **中继**（第 6.1、6.2 节）：S1_g、V1_g 每组 40 个（在 [40, 80] 内标定）；S1 → N1 改为按组。
- **累加型 L**（第 7.1、7.3 节）：
  - 结构：10 个细胞，阈值 EL + 30 mV ±10%，适应 b_L 200 pA、τw 50 ms，弱的独立背景；
  - 输入：N1_g、M1_g 各接 7 个，慢受体 τR 5 / τD 30 ms，基础强度约 0.88，增益在 [0.5, 2] 内标定；
  - 一次装入定义为 50 ms 内 ≥ 5 次放电。
- **E1 的适应**（第 5.1 节）：b 在 [5, 20] pA 内标定；静息点燃率沿用 v2 `restMetrics` 的定义。
- **两次水平检查**（第 4.7、6.4 节）：预热后与预测抵消训练后各测一次冻结静息，L 静息 ≤ 0.5 Hz。
- **第 6.4 节**改为以单一 L 为准：边界检出、方向读出、不误装入（在场、静息、二次装入）、保持、静息与对比度、不依赖 E2、旧验证。另加三项**机理指标**（去同步、适应波、E1 台阶余量），作设计值记录。

### 3.3 实现

1. **按特征的边界通道**（`world.mjs`、`context.mjs`、`expect.mjs`、`actions.mjs`、`build.mjs`、`readout.mjs`）
   - 场景一的 context 与 outputs 改为每个特征一个通道，方向记作 `'±'`；场景三、四的 outputs 也改为 `'±'`；动作通道保持 `'+'`，只在动作开始时装入。
   - L、C、P、Q、Z、D、U 按通道各建一套；L_g 同时接收 N1_g 与 M1_g。
   - `readout.mjs` 新增 `boundaryDirection(net, e1Ids, t)`：比较 E1_g 在 [t, t+50 ms] 与 [t−100 ms, t] 的平均频率，前者高记为出现，否则记为消失。
   - 新增 `loadEvents(spikes, {windowMs: 50, minSpikes: 5})`：把 L_g 全部细胞的放电按时间排序，凡是 50 ms 内凑够 5 次放电，就记一次装入。装入的时刻取凑够第 5 次放电的那一刻；装入强度取从该窗口第一次放电起 50 ms 内的放电数。一次装入之后，从它的窗口结束起至少隔 20 ms 才计下一次。第 6.4 节的"0–100 ms 内发生一次装入"按装入时刻判断。
2. **共享比例上限**（`build.mjs` 的 `connectByIndegree`）
   - 对 evidence、negativeEvidence、predictionInhibition、negativeInhibition、prediction、negative、localPrediction、localNegative、load 这些通路，取 k = min(k_ref, n_pre, ⌊0.35·n_pre⌋)，p = k / n_pre，强度乘 k_ref / k。
   - 其余通路保持 k = min(k_ref, n_pre)。
   - `loopRoute` 记录 k_ref、k、n_pre、共享比例与补偿倍数。
3. **中继**（`errors.mjs`）
   - S1_g、V1_g 的规模由参数 `relaySize` 决定（默认 40，诊断还测 80）；
   - S1_g → N1_g 按组连接（突触前只有本组的 S1_g）；
   - 其余连接的强度与可塑性设置不变。
4. **累加型 L**（`context.mjs`）
   - L_g 的 10 个细胞：C 100 pF；第 q 个细胞（q = 0…9）的阈值为 EL + 30 mV × (1 + 0.1·(2q/9 − 1))；适应 b 200 pA、τw 50 ms；背景 `L` 2 Hz（`BACKGROUND_RANGES.L` 设为 [0, 6]）。
   - N1_g → L_g、M1_g → L_g：`kind: 'slow'`，τR 5 ms、τD 30 ms，通路名 load，k_ref 7。基础强度在代码里按公式算出：3 × (20/7) × (0.78 + 0.56) / slowCharge(5, 30)，再乘参数 `loadGain`（默认 1，范围 [0.5, 2]）。0.78 与 0.56 写成具名常数并注明出处（第 7.2 节的电荷表）。
   - U↑_g → L_g、L_g → C_g、L_g → Z_g 的连接方式不变。
   - 影子 L：每个通道另建增益为 0.5、0.75、1.5、2 的副本。结构与正式 L 相同，连接与背景独立抽样，不向任何群投射；默认构建没有影子。
   - 旧的 `loadGainPlus`、`loadGainMinus` 与按方向的影子删除。
5. **E1 的适应**（`build.mjs`）：参数 `e1Adaptation`（b，单位 pA，默认 20，范围 [5, 20]），同时写入 E1 群的细胞参数与 E1 模块的 `b`，并保存在状态中。
6. **两次水平检查**（`protocol.mjs`）
   - 预热收敛后与预测抵消训练结束后，各测 3 s 冻结静息（E2 另测 10 s）。
   - 每次都输出 `restInRange`：E1 2–5、I1 5–20、N1 与 M1 2–5 Hz，空闲 E2 ≤ 1 Hz，已提交 E2 0.5–2 Hz，L 各组 ≤ 0.5 Hz。
   - 同时输出 E1 静息点燃率：3 s 冻结静息中，任一组在 20 ms 分箱上超过 10 Hz 的分箱比例。
7. **机理指标**（`demo/loop-diag.mjs`）：定义与探查脚本 `analyze.mjs`、`phases.mjs` 相同，按第 6.4 节的设计值输出比值与是否达标。
   - **静息段**：预热后与训练后的 3 s 静息，加上 D4 每次试次消失后 300 ms 到下一次出现之间。
   - **在场段**：D6 每次呈现开始 300 ms 之后。
   - **成团放电**：对每个 N1_g、M1_g，统计 5 ms 滑动窗口（步长 1 ms）内 ≥ 5 个脉冲的事件，相邻事件至少隔 20 ms；分别给出静息段与在场段的每秒次数。
   - **法诺因子**：静息段内 20 ms 计数的方差 / 均值。
   - **适应波**：M1_g 在出现后 100–300 ms（D4 训练后）的平均频率，除以 M1_g 在 D6 呈现 1–5 s 的平均频率；N1_g 在消失后 200–400 ms 的平均频率，除以训练后的静息频率。
   - **E1 台阶余量**：统计量 = E1_g 在 [t, t+40 ms] 的平均频率减去 [t−200 ms, t] 的平均频率。
     - 出现余量 = 出现后 −10…+30 ms 内该统计量最大值的最小值（对试次取最小），除以状态内（在场段与静息段，每 2 ms 一个 t）的最大正值；
     - 消失余量 = 消失后 −10…+50 ms 内最小值的绝对值的最小值，除以状态内最小值的绝对值。
   - **L 指标**：对正式 L 与每组影子 L，都按第 6.4 节第 1–5 条计算：
     - 出现、消失各自的检出比例；
     - 方向读出正确率；
     - 在场、静息误装入比例与二次装入比例；
     - D6 中 L 是否高于静息；
     - 两次静息中的 L 频率。
8. **场景四的 E2 静息来源**（只记录）：训练后做三段 10 s 冻结静息：照常；N1 → E2 置零；E1 → E2 置零。每段结束后恢复原值。记录已提交单元在三段中的频率，以及它的 I2 → E2 权重（均值、中位数、≥ 0.95·wMax 的比例）。
9. **结果写入**：沿用 diag3 的重试与另存机制；总调度不因单个运行失败而中止。
10. **结构检查**（`verify/loop-build.mjs`，供第 5 节使用）：
    - 每个特征一个通道，场景一 3 个，没有按方向的 L、C、P、U；
    - 共享比例表：所有受限通路的 k / n_pre ≤ 0.35，补偿倍数正确；
    - 中继规模；S1 → N1 只连本组；
    - L 的阈值梯度、b_L、τw、背景，输入为 slow 5/30、各 7 个、强度与公式之差 ≤ 1e-12；
    - E1 的 b 与设定值一致；默认构建没有影子 L；
    - E1 → P、E2 → P 的连接不存在。

一个运行合格，需要同时满足（三个特征分别判断，取最差的那个）：

1. 预热在 300 s 内收敛；两次水平检查都通过（含 L ≤ 0.5 Hz）。
2. 两次静息的 E1 点燃率都 ≤ 5%。
3. 去同步：N1、M1 每组的成团放电在静息段 ≤ 0.5 次/s、在场段 ≤ 1 次/s；静息段的法诺因子 ≤ 2。
4. 适应波：M1 的比值 ≤ 1.5；N1 的比值 ≤ 1.5。
5. E1 台阶余量：出现 ≥ 2，消失 ≥ 1.5。
6. 第 6.4 节第 4 条（保持）与第 5 条的对比度（S1 ≥ 2 倍）；训练后 N1、M1 的 PSTH 峰值 ≥ 基线 + 10 Hz。

### 第二步：选 L 增益（只在第一步合格的运行上）

候选是（运行，增益）的组合，增益取 0.5、0.75、1、1.5、2。合格需要同时满足（三个特征分别判断）：

1. 出现、消失的检出各 ≥ 90%（第 6.4 节第 1 条）。
2. 方向读出正确率 ≥ 95%（第 2 条）。
3. 在场误装入、静息误装入、二次装入各 ≤ 5%（第 3 条）。
4. D6 中该增益的 L 不高于静息水平（第 4 条）。
5. 两次静息中该增益的 L ≤ 0.5 Hz。

### 排序

在合格的组合中依次比较：
1. 各项误装入比例的最大值，越小越好；
2. 检出比例的最小值，越大越好；
3. 中继 40 优先于 80；
4. b 越大越好（越接近 v2 原值）；
5. s_eq 越小越好；
6. 增益越接近 1 越好。

### 场景四复核

- 选出的（中继，b，s_eq）是 (40, 20, 4) 或 (40, 10, 4) 时，用对应的场景四运行复核；否则在选定点补跑一个场景四运行（唯一的补跑）。
- 复核要求：
  - 两次水平检查通过，已提交 E2 单元 0.5–2 Hz，E1 点燃率 ≤ 5%；
  - "红""甜""苦"满足第一步第 3–6 条；
  - "甜""苦"在选定增益下满足第二步第 1–5 条。

### 结果

- 第一步没有合格的运行：停止，按第 8 节报告，并逐项标出每个运行没通过的条目。
- 第二步没有合格的组合：停止，同样报告。
- 场景四复核不通过：停止，报告中附上 D8 的 E2 静息来源。
- 否则进入第 5 节。

## 8. 报告格式（W4-diag4 与 W4-r4 共用）

记录 `docs/loop/attempts/<包名>.md` 正文不超过 200 行。逐项明细放在结果目录的独立文件里，正文只放链接。按以下顺序：

1. **状态与决定**：一句话写状态；然后写选出的参数，或停止的原因。停止时要写到具体的条目和运行。
2. **机理指标总表**：每个运行一行，列为：
   - 两次水平检查是否通过；两次静息的 E1 点燃率；
   - N1、M1 在静息段与在场段的成团放电（次/s）；静息段法诺因子；
   - M1 适应波比值、N1 反弹比值；E1 出现余量、消失余量。

   每格给最差特征的实测值，并标出是否达到设计值。
3. **L 总表**：第一步合格的运行 × 5 个增益，每格给出：
   - 出现、消失检出的最小值；方向读出正确率的最小值；
   - 在场、静息、二次误装入的最大值；
   - D6 是否高于静息；两次静息中 L 频率的最大值。
4. **场景四表**：两次水平检查；已提交 E2 单元在 D8 三段中的频率；I2 → E2 权重统计。
5. **选择过程**：逐条写出第 4 节规则的应用结果。
6. **图**（在结果目录，正文链接）：
   - 切换时间进程：选定的运行（或第一步最好的运行）与 s1-r40-b20-e4 各一张，版式与 `probe-mechanism/mechanism-switch.png` 相同；
   - 成团放电触发平均：同样两个运行，版式与 `mechanism-volleys.png` 相同；
   - 机理指标网格；
   - L 选择网格。
7. **工程信息**（一段）：源码哈希、缓存核对结果、各运行用时、程序故障与重跑。
