# bio-brain：逐层生物脑模型

从单个神经元一路搭到脑结构，共五层：

1. 单个神经元
2. 突触连接
3. 赫布学习
4. 网络里的吸引子与有向通道
5. 由多个网络组成的脑结构（方向环、海马、前额叶、皮层规则）

每一层都有一个验证脚本，用数字证明这一层具备该有的性质；下一层只用上一层已验证过的东西。

每一层同时记两本能量账：

| 账 | 是什么 | 最低点在哪 |
| --- | --- | --- |
| **代谢账（ATP）** | 真实耗掉的能量：维持静息、动作电位、突触传递（钠钾泵、钙泵、Cl⁻ 外排） | 全体静默 |
| **动力学账（能量函数）** | 网络"要维持这个状态需要多少外力"；对称连接时它沿动力学只降不升 | 吸引子 |

两者的关系是本项目要讲清楚的事。

- 吸引子不是代谢最低点。
- 但排除"全体静默"这个平凡解后，确实存在"能完成任务的最省能吸引子"（第 4 层）。
- 赫布学习让"一起激活"变省，省的是上游驱动，不是单次传递（第 3 层）。

## 第 1 层：单个神经元

`src/L1-neuron/hh.mjs`：标准 Hodgkin–Huxley（乌贼参数，T 按 Q10 = 3 缩放门控速率）。

漏电拆成 Na⁺ 漏和 K⁺ 漏两部分，使合并后的反转电位等于 E_L。这样静息时虽然净电流为零，Na⁺ 仍在不断漏进来，钠钾泵要持续付费，这就是静息成本。

\[
\text{ATP} = \frac{\int I_{Na}^{\text{内流}}\,dt}{e} \times \frac{1}{3}
\]

`calibrateHH` 给出：
- 静息成本（ATP/ms/cm²）；
- 一次动作电位的成本（只在放电本身里积分，扣掉同时段的静息漏）；
- 重叠系数（Na⁺ 内流 / 把膜电容充到峰值所需的最少电荷 C·ΔV）。

重叠系数大，是因为 Na⁺ 内流与 K⁺ 外流在时间上重叠，互相抵消；温度升高时通道变快、重叠变少，所以更省能。

`src/L1-neuron/lif.mjs`：点神经元（200 pF、10 nS，即 20000 µm²、膜电阻 20 kΩ·cm²），带适应电流 w。`mammalianCosts` 按哺乳动物式的重叠系数 1.3 缩放放电成本，按漏电导缩放静息成本，得到：
- 每次放电约 5.7×10⁷ ATP；
- 静息约 5.1×10⁸ ATP/s（Attwell & Laughlin 2001 估算大鼠神经元维持静息约 3.4×10⁸ ATP/s，同一量级）。

## 第 2 层：突触

`src/L2-synapse/synapse.mjs`：一个连接 = `contacts` 个释放位点，每个以 p·R 的概率释放一个囊泡（R = 可用囊泡比例，被短时程压抑消耗、按 τ_rec 恢复）。

- 电流：I = Σ g(t)·B(V)·(E − V)。
- 镁阻断：B(V) = 1/(1 + [Mg]/3.57·e^{−0.062V})。正是它让 NMDA 成为"突触前有递质"且"突触后已去极化"的同时检测器。
- 突触前成本：按囊泡计（递质回收、囊泡循环、Ca²⁺ 外排）。
- 突触后成本：按真实流过受体的离子计（Na⁺ 1/3 ATP、Ca²⁺ 1 ATP、Cl⁻ 1/2 ATP）。

突触越强，单次传递越贵——这在第 3 层会变得重要。

## 第 3 层：赫布学习

`src/L3-plasticity/calcium-rule.mjs`：

\[
\tau\frac{d\rho}{dt} = -\rho(1-\rho)(\rho^*-\rho) + \gamma_p(1-\rho)[c>\theta_p] - \gamma_d\,\rho\,[c>\theta_d]
\]

- 钙 c 有两个来源：突触前脉冲经 NMDA 进来（延迟 D），突触后放电反传到树突、经电压门控钙通道进来。
- "前在后前"时两份钙叠加越过高阈值 → 增强；"后在前前"时只越过低阈值 → 减弱。
- 效能 ρ 映射到第 2 层突触的量子电导缩放。
- `eta > 0` 时加入 NMDA 同时检测：突触后放电时，已结合递质的 NMDA 受体被挪开镁塞，多进一份钙。

`src/L3-plasticity/circuit.mjs`：把第 1–3 层拼成脉冲回路。泊松上游驱动的放电与突触成本记到 `drive` 类别。

**"一起激活更省"的实验**（`verify/L3-hebbian.mjs`）：

1. 10 个两两互连的神经元先被爆发式地一起激活 15 s，突触从 ρ = 0.05 增强到 0.59（强度 ×8）。
2. 冻结可塑性后，用二分法找出"让这群神经元平均放到 10 Hz"所需的最少上游驱动：学习前每条输入 41.3 Hz，学习后 29.8 Hz。
3. 整个系统（含上游）的 ATP 从 7.17×10¹¹ 降到 5.20×10¹¹ ATP/s（−27%）。但群体自身的开销略升（1.10×10¹⁰ → 1.18×10¹⁰），因为每个囊泡的突触后成本从 5.3×10⁴ 升到 4.3×10⁵ ATP。

结论：赫布学习省下的是"外部需要推多少"，不是单次传递的成本。

## 第 4 层：网络里的吸引子与有向通道

`src/L4-network/rate-network.mjs`：

\[
\tau\dot r = -r + g(Wr + b + I - a),\quad \tau_a\dot a = -a + k_a r
\]

\[
E(r) = -\tfrac12 r^\top W_s r - (b+I-a)^\top r + \tfrac1\beta\sum[r\ln r + (1-r)\ln(1-r)]
\]

- 对称部分 W_s 定义能量地形：W 对称、a 固定时 dE/dt ≤ 0，极小值就是吸引子。
- 反对称部分 W_a 不能写进任何能量函数，它是让状态沿固定方向流动的"风"。
- 疲劳 a 把当前的井慢慢填浅。

`src/L4-network/learning.mjs`：第 3 层钙规则在群体层面的平均效果。

| 规则 | 来自第 3 层的什么 | 作用 |
| --- | --- | --- |
| 协方差规则（对称） | 一起高频激活 → 双向增强 | 形成吸引子 |
| 时间不对称项 λ·ξ^{μ+1}ξ^{μ⊤} | 先后激活 → 单向增强 | 形成有向通道 |
| 突触有上限的版本 | 单个突触强度有限 | 小集合撑不起来 |

`src/L4-network/metabolism.mjs`：速率状态的 ATP = N × 静息 + Σ 放电率 × (单次放电 + 输出突触)，常数来自第 1、2 层。

验证结果见总览表。其中两条直接回答"排除静默后有没有能耗极小"：
- 吸引子状态（4.0×10¹¹ ATP/s）比静默（1.0×10¹¹）贵，所以吸引子不是代谢最低点；
- 但在突触强度有上限时，只有每个模式 20 个神经元（f = 0.1）的编码能完成补全：更稀疏的撑不起自己，更密的互相干扰。能工作的最省能吸引子就落在这里。

脉冲层面：40 个兴奋 + 10 个抑制的 LIF 集合是双稳态的，短暂刺激后自持放电（约 100 Hz），短暂抑制后回到静默；持续态的 ATP 约是静默的 20 倍。

## 第 4 层（脉冲版）：外界刺激下的涌现

上面的速率网络里，吸引子与有向通道的权重是按公式从模式直接算出来的。这一节换成**真实的神经元与突触在外界刺激下自己学**：`src/L4-network/spiking-network.mjs`。

- 方程与第 1–3 层逐项相同，只是把同一突触后神经元的同类受体电导合并存储（线性叠加，严格等价）。
- `verify/L4-emergence.mjs` 先在一个小回路上与逐个突触的实现对拍：放电时刻、每个突触的效能、ATP 全部逐拍相同。

**网络**：
- 100 个兴奋性 + 25 个抑制性 LIF 神经元；
- 兴奋→兴奋突触随机连接（概率 0.5、每连接 10 个接触点），约 5000 个，全部可塑，起点都很弱（ρ = 0.1）；
- 每个神经元有 60 条泊松背景输入（6 Hz）。

**刺激**：
- 4 个刺激组，每组的原型是 20 个神经元。
- 每次只呈现**变体**：原型里随机 16 个 + 4 个无关神经元，200 ms，间隔 300 ms，共 150 次。原型本身从未出现过。
- 然后让相邻刺激组按 A→B→C→D 紧接着出现（每组 40 ms、时间压缩，像海马 θ 周期里依次放电的位置细胞），共 40 遍。

**结果**（`node demo/fig2-network.mjs`，图在 `figures/`）：

| 问题 | 学习前 | 学习后 |
| --- | --- | --- |
| 特征性激活：同一组不同变体引起的全网响应相关（异组） | 0.46（−0.12） | 0.67（−0.22） |
| 吸引子（补全）：只刺激原型的 8 个神经元，其余 12 个被拉起 | 0% | 50% |
| 能量极小：维持 20 个神经元放到 10 Hz 所需的最少外部驱动（原型 / 经历过的变体 / 随机） | 17.5 / 16.9 / 18.1 Hz | **13.1** / 15.5 / 16.7 Hz |
| 同上的整个系统 ATP（×10¹² /s） | 2.95 / 2.91 / 3.00 | **2.69** / 2.86 / 2.95 |
| 突触结构：组内 / 组间平均效能 ρ | 0.10 / 0.10 | 0.40 / 0.16 |
| 有向通道（结构）：相邻组正向 / 反向平均 ρ | 0.164 / 0.159（序列训练前） | 0.410 / 0.062 |
| 有向通道（功能）：持续刺激一组 150 ms，下一组 / 上一组被拉起 | 1.7 / 1.7 Hz（序列训练前） | 10.0 / 0.1 Hz |

- 图 2（`fig2-responses.png`）：学习前放电散落在被刺激的神经元上；学习后，每个变体都引起整组的同步群体爆发，没被刺激的原型成员也一起放电，不属于原型的神经元被压下去。
- 图 3（`fig3-weights.png`）：突触矩阵从均匀长成 4 个对角组块；序列训练让"上一组 → 下一组"的块变强（蓝），反向变弱（红）。
- 图 4（`fig4-sequence.png`）：训练后刺激 A，A 的每次爆发之后 B 紧跟着爆发，C、D 不动。

**为了让这些现象在真实脉冲网络上出现，需要加的机制**（每一个都有实验依据，单靠赫布学习不够）：
1. **只靠赫布学习会失控**：Graupner & Brunel 的原参数（DP 组）下，单个突触后脉冲的钙（2）就超过增强阈值。放进网络后，任何放电神经元的全部输入都被推到 ρ ≈ 0.5，所有突触一起变强，全网一起放电。
2. **NMDA 依赖版钙规则**（`GB_NMDA`）：
   - 只有突触前放电：钙低于减弱阈值，突触不变；
   - 只有突触后放电：只轻微减弱（异突触压抑）；
   - 突触前先放、突触后随即放电：同时检测项越过增强阈值，增强；
   - 突触后先放、突触前随后：延迟到达的突触前钙落进减弱区间，特异性减弱。
   - 它保留经典 STDP 的不对称窗（+5 ms 增强 0.060，−5 ms 减弱 0.132）；有向通道靠的正是这个负半边。
3. **抑制性可塑性**（Vogels et al. 2011）：突触后放电高于目标频率时，抑制它的突触变强，局部维持兴奋/抑制平衡，防止全局爆发。
4. **异突触竞争**：一个神经元的输入突触平均效能有预算（0.2），超出就全部等量下调——一部分变强，别的就得变弱。没有它，集合长出来后会互相合并。
5. **背景输入**：真实皮层神经元在背景突触轰击下平时停在阈值下几毫伏，学到的组内连接只需再推一点就能补全；背景太弱（2 Hz）时补全只有 15%。
6. **时间压缩的序列**：每组 100 ms 时，交界处的增强被之后约 80 ms 的"只有突触后放电"抵消，不长有向通道；压缩到 40 ms 后正向从 0.17 升到 0.41。

**局限**：
- 这是 100 个神经元的网络，吸引子都比较浅：补全只到一半；
- 有向通道一次只能推一步（刺激 A 时 C、D 不动）；
- 网络撤掉刺激后不会自持（低频持续活动仍是已知缺口）；
- 学习时间常数加速了 5 倍。

## 第 4 层（脉冲版）：新刺激激活了哪些吸引子

`demo/fig5-decode.mjs`（图 5）。训练与上一节相同，结果缓存在 `cache/`。

**怎么读**：
1. **吸引子从哪来**：不看原型标签，只看网络学到的突触。井由对称部分决定、有向通道属于反对称部分，所以只保留两个方向都强的连接（取 min(ρ_ij, ρ_ji)），在上面做标签传播，再合并被切开的同一口井、剔除挂靠的成员。找到 4 个吸引子：B、D 纯度 100%；A、C 各挂着几个原型之外的神经元（纯度 69%、76%），它们在学习时常作为"噪声"与这两组一起放电。
2. **激活度**：标定每个吸引子静息时与整组被完全驱动时成员的平均放电，换算到 0–1。
3. **吸引子自身的贡献**：没被刺激的成员被拉起多少。只有这一项说明吸引子真的被激活了，而不只是刺激直接打在它的成员上。
4. **对照**：同样的刺激施加在未训练的网络上。

表中是激活度，括号里是没被刺激的成员的放电（训练后 / 未训练）：

| 新刺激 | A | B | C | D |
| --- | --- | --- | --- | --- |
| A 的残缺版 + 噪声（A 的 10 个 + 10 个随机） | **0.66**（6.6 / 0.1 Hz） | 0.46（4.9 / 0.1） | 0.12 | 0.09 |
| 只有 A 的 10 个 | **0.71**（9.0 / 0.0 Hz） | 0.43（6.2 / 0.0） | 0.00 | 0.18 |
| A 与 C 等强混合 | **0.47**（3.6 / 0.0 Hz） | 0.05 | **0.43**（2.3 / 0.0） | 0.07 |
| A : C = 1 : 3 | 0.03 | 0.00 | **0.66**（6.9 / 0.0） | 0.22 |
| 只有 C 的 10 个 | 0.01 | 0.00 | **0.74**（8.4 / 0.0） | 0.23 |
| 全新：只落在原型之外 | 0.22（0.1 / 0.3） | 0.10 | 0.29（0.4 / 0.4） | 0.08 |

- **认得出是谁**：只给 A 的一半成员、外加一半噪声，读出仍是 A。
- **多个吸引子与各自强弱**：等强混合时 A、C 同时被读出，比例 1:3 时 C 占主导。
- **强度互相竞争，不是相加**：A 单独出现时把自家成员拉到 9.0 Hz，与 C 同时出现时只到 3.6 Hz。两个吸引子共用同一群抑制性神经元。
- **有向通道带起下游**：刺激 A，B 被带起（0.43），B 成员的首次放电比 A 成员晚（41 对 33 ms）；刺激 C，D 被带起。刺激 A 时 D 的一点激活来自第一阶段学习中意外形成的 A→D 连接（ρ 0.27）。
- **全新刺激读出"没有吸引子"**：没被刺激的成员几乎不动，与未训练网络一样；那一行的激活度来自 A、C 挂靠的外部神经元被直接刺激。

## 万能近似定理与多层迭代激活

代码：`src/L4-network/attractor-layer.mjs`（速率版吸引子层与读出）、`demo/uat.mjs`（图 6、图 7）、`demo/fig8-two-layer.mjs`（图 8，真实脉冲网络）。验证：`verify/L4-uat.mjs`、`verify/L4-two-layer.mjs`。

### 定理说了什么，在我们的网络里各是什么

万能近似定理（Cybenko 1989；Hornik 1991；Leshno et al. 1993）：一层足够多的非线性单元（非线性只要不是多项式），加上一个系数可以任意调的线性读出，能把有界区域上的任意连续函数逼近到任意精度。径向基网络同样成立（Park & Sandberg 1991）。它是存在性定理：不说系数怎么学，也不说要多少单元。

| 定理要求 | 我们的网络 |
| --- | --- |
| 非线性单元 | 一个吸引子。它的激活度随刺激的变化是一条以原型为中心的调谐曲线：刺激与原型重叠到一定程度才招募（阈值 + 组内正反馈），别的吸引子更像时被共享抑制压下（竞争）。相当于一个归一化的径向基单元 |
| 单元足够多 | 吸引子数随网络规模增长；竞争性赫布学习把原型放到刺激真正出现的地方 |
| 为目标调过的读出 | 第 4 层的赫布学习是无监督的，只决定"有哪些吸引子"，不拟合任何目标。目标要靠一条带教学信号的读出：三因素规则 Δv = α·δ·r，δ 是多巴胺或攀缘纤维报告的误差；负系数经抑制性中间神经元实现 |

大脑里有现成的"一层扩张 + 有监督读出"：小脑（颗粒细胞 → 浦肯野细胞，攀缘纤维报告误差；Marr 1969、Albus 1971）；果蝇蘑菇体（每侧约 2000 个 Kenyon 细胞稀疏编码，APL 抑制只让少数赢者保持激活，多巴胺神经元门控输出神经元上的可塑性）；纹状体（皮层 → 纹状体，多巴胺）。

**速率版吸引子层**（为了跑大规模实验）：一个单元代表脉冲版里的一个吸引子，输出是它的激活度（0–1）。保留脉冲版的三件事：
- 原型：竞争性赫布学习把活跃吸引子的原型拉向当前刺激；
- 竞争：只有最像的 k 个保持激活，强度按超出第 k+1 名多少分级（共享抑制）；
- 侧向联系：同时激活的吸引子之间赫布增强，激活后再沉降几拍让联系参与（组间连接）。

很少赢的吸引子阈值下降，避免永远用不到的"死"吸引子。

**刺激与目标**：(x, y) ∈ [0,1]²，用群体编码送入（15 个神经元调谐到 x，15 个调谐到 y）。四个目标函数：
- f_add = (x+y)/2：可加；
- f_mul = xy；
- f_sin = ½ + ½·sin 2πx·cos 2πy：没有可加成分；
- f_xor = [x > ½] 异或 [y > ½]：不连续的棋盘。

误差是 1000 个没见过的测试点上的归一化均方根误差（0 = 完美，1 = 只会猜平均值）。读出取最小二乘最优解，衡量表示本身能做到什么；三因素规则在线学到的另行报告。

### 实验一：一层吸引子 + 读出（图 6）

| 表示 | f_add | f_mul | f_sin | f_xor | f_sin（加上侧向联系） |
| --- | --- | --- | --- | --- | --- |
| 原始群体编码，直接线性读出 | 0.012 | 0.393 | 1.006 | 1.000 | — |
| 4 个吸引子 | 0.744 | 0.780 | 0.999 | 0.999 | 0.999 |
| 16 个 | 0.265 | 0.276 | 0.584 | 0.619 | 0.584 |
| 64 个 | 0.162 | 0.168 | 0.241 | 0.365 | 0.505 |
| 256 个 | 0.105 | 0.101 | 0.136 | 0.299 | 0.269 |
| 512 个 | 0.072 | 0.070 | 0.111 | 0.261 | 0.159 |

（前四列只有竞争；4、16 个时每次只有 1 个吸引子活跃，侧向联系不起作用。）

- **原始编码的线性读出只能表示"x 的函数 + y 的函数"**：f_add 几乎完美，f_sin、f_xor 完全读不出。
- **加一层吸引子，四个函数的误差都随吸引子数持续下降**：
  - f_sin 从 64 个到 512 个，误差大约按 N^−0.4 下降；在二维输入上，局部基分段近似的速率是 N^−1/2。
  - f_xor 有跳变，只有边界附近的吸引子出错，所以下降更慢，约 N^−0.16。

  这就是万能近似：要多精确，就要多少吸引子。维数灾难也同样存在：d 维刺激大约需要 ε^−d 个吸引子。
- **代价**：f_add 这种原始编码里线性就有的量，吸引子层反而读得更差（0.012 → 0.072），因为竞争把连续的位置量化成了有限个原型。
- **三因素规则**（在线、局部，只用误差 × 突触前活动）学 200 遍：256 个吸引子、f_sin 误差 0.142，最优解是 0.136。

**侧向联系越学越"粘"**（64 个吸引子，即上表最右一列的来源）：

| 学习次数 | 1500 | 3000 | 6000 | 12000 |
| --- | --- | --- | --- | --- |
| f_sin 误差 | 0.275 | 0.388 | 0.505 | 0.535 |
| 测试集上的不同激活模式 | 199 种 | 123 种 | 26 种 | 18 种 |
| 最强侧向联系 | 0.53 | 0.81 | 0.96 | 0.97 |

只有竞争时，同样 64 个吸引子学 1500–12000 次，误差稳定在 0.23–0.25，测试集上约 250 种模式。加上侧向联系后，经常一起激活的吸引子之间的联系越学越强，被粘成更大的复合吸引子：模式变少，表示更类别化，近似更粗。同一层里随时间迭代（侧向联系参与沉降），效果和往上叠层一样（见实验三）。

### 实验二：分开的模块 → 第二层把它们组合起来（图 7 左）

第一层分成两个模块：16 个吸引子只看 x，16 个只看 y（像不同的感觉通道或皮层区）。第二层的刺激就是第一层 32 个吸引子的激活强度。

| f_sin / f_xor 误差 | 下层硬性（每个模块只留 1 个赢者） | 下层分级（每个模块 3 个按强度共同激活） |
| --- | --- | --- |
| 只有第一层 | 1.006 / 1.004 | 1.003 / 1.000 |
| + 第二层 64 个吸引子 | 0.994 / 0.981 | 0.489 / 0.547 |
| + 第二层 256 个吸引子 | 0.812 / 0.881 | 0.434 / 0.468 |

- **分开的模块无论多精细，都表示不了 x 与 y 的交互。**
- **第二层长出合取吸引子**：它学到"哪些下层吸引子经常一起激活"，形成"x 在这附近且 y 在那附近"这样的合取吸引子，交互就能读出了。64 个时误差 0.489，与直接看联合输入的一层 64 个吸引子（有侧向联系，0.505）相当。
- **前提是按强度分级传递**：
  - 下层只传"谁赢了"时，x 的第 3 档与第 4 档在第二层看来，和第 3 档与第 12 档一样不同。第二层没法在相近的组合之间插值，只能给 16 × 16 种组合各配一个吸引子。
  - 几个相近的吸引子按强度部分激活时，相似结构才能传上去。

### 实验三：一层够用之后继续无监督地往上叠（图 7 中、右）

第一层是实验一里 64 个、有侧向联系的吸引子层，往上每层都以下一层的激活强度为刺激。

| 层（吸引子数） | f_sin | 读出 x 的误差 | 象限类别正确率 | 不同激活模式 | 加噪前后表示相关 |
| --- | --- | --- | --- | --- | --- |
| 第 1 层（64） | 0.505 | 0.239 | 90.6% | 26 种 | 0.835 |
| 等宽：第 2–5 层（各 64） | 0.570 | 0.257 | 84.5% | 18 种 | 0.834 |
| 变窄：第 2 层（32） | 0.570 | 0.257 | 84.5% | 18 种 | 0.834 |
| 变窄：第 3 层（16） | 0.619 | 0.414 | 78.1% | 16 种 | 0.836 |
| 变窄：第 4 层（8） | 0.818 | 0.841 | 57.9% | 8 种 | 0.844 |
| 变窄：第 5 层（4） | 0.860 | 0.998 | 45.5% | 4 种 | 0.862 |

- **不增加信息**：数据处理不等式 I(刺激; 第 n 层) ≤ I(刺激; 第 n−1 层)。没有教学信号时，多叠的层只能保持或丢失关于刺激的信息。等宽堆叠里，第 2 层把相近的模式并掉一些；从第 3 层起，每层只是把下一层的码换个编号，什么都不再变。
- **逐层变窄是粗粒化**：类别越来越少，位置细节逐层丢掉，对输入噪声只略稳一点。
- **无监督的粗类别不会自动对齐实验者心中的类别**：顶层 4 个吸引子只对上 45.5% 的象限（随机猜是 25%）。均匀的刺激世界没有天然的类别，粗类别只是对空间的任意划分。

### 真实脉冲网络上的两层（图 8）

**设置**：
- 第一层：上一节训练好的网络（吸引子 A、B、C、D 与有向通道 A→B→C→D），不再学习。
- 绘图：第一层对刺激的响应 → 各吸引子的激活度 → 第二层对应 20 个神经元的输入速率 = 背景 6 Hz + 激活度 × 24 Hz。
- 第二层：全新的同构网络（同样的神经元、突触、学习规则、起点），只经历两个"物体"共 100 次：X = A + C、Y = B + D（每个部件随机取原型的 12 个成员刺激第一层）。
- 对照：同一初始状态、没有学习的第二层。

**第二层学出的吸引子**（只看第二层学到的突触找）：
- 35 个神经元 = A 组 20 + C 组 13 + 其他 2；
- 48 个神经元 = B 组 20 + D 组 20 + C 组 7 + 其他 1。

C 组被两个物体瓜分了：第一层的 B 经有向通道带起 C（画出来的 Y 里 C 的激活度为 0.32），第二层就把一部分 C 绑进了 Y。上层的整体不只包含一起出现的部件，也包含下层"预测接下来会出现"的部件。

| --- | --- | --- |
| X（A + C） | 0.64 / 0.23 / 0.38 / 0.15 | 15.3 / 0.0 / 9.9 / 0.0 ｜ 13.4 / 1.4 / 5.8 / 0.8 |
| Y（B + D） | 0.03 / 0.64 / 0.26 / 0.40 | 0.0 / 15.4 / 5.5 / 15.0 ｜ 0.0 / 11.8 / 1.6 / 6.4 |

| 只给 B | 0.00 / 0.67 / 0.90 / 0.03 | 1.5 / 15.5 / 16.9 / **4.6** ｜ 0.0 / 11.3 / 16.0 / 0.0 |

- **长出"吸引子的组合"这一级吸引子**：第二层用的是和第一层完全相同的机制，第一层的吸引子在这里就是部件。
- **跨层补全**：只给一个部件，第二层把同一物体的另一个部件拉起来（粗体）；没学过的第二层不会。
- **物体之间竞争**：只给 A 时，第一层经通道带起了 B（0.45），第二层的 B 组却被物体 X 压到 0.6 Hz（没学过时 5.1 Hz）。
- **没学过的组合被解释成一个学过的物体**：A + D 在第二层成了 X，补出 C，压下 D（2.1 对 6.1 Hz）。
- **细节在绘图一步被丢弃**：用 A 的前 10 个成员和后 10 个成员做两种刺激。刺激本身相关 −0.11，第一层放电相关 0.82，画出的激活度相关 0.99，第二层放电相关 0.98。越往上越只认"是哪个吸引子"。

### 抽象程度相同，丢掉的细节对不对（`demo/aligned-abstraction.mjs`）

同样 4 个吸引子；世界里"发生什么"由所在象限决定。误差引导：每个吸引子学一个后果预测，原型的竞争性赫布更新再乘一个第三因子（赢者对实际后果的预测减去机会水平，像多巴胺）。

| 3 个随机种子 | 无监督 | 误差引导 |
| --- | --- | --- |
| 象限正确率 | 50.7% / 50.1% / 47.6% | 88.0% / 87.9% / 87.9% |
| f_xor 误差 | 0.999 / 0.975 / 1.000 | 0.640 / 0.642 / 0.642 |
| 读出 x 的误差 | 1.000 / 0.839 / 0.260 | 0.540 / 0.540 / 0.540 |

- 无监督的划分随初始化而变：种子 13 恰好沿 x 切开，保住了 x、丢光了 y。它丢掉了细节，但丢的不是"无关的"细节。
- 误差引导的划分每次都收敛到同一个答案（原型落在四个象限中心附近）。读出 x 的误差稳定在 0.54：只知道"在左半边还是右半边"时的理论值是 0.5。它恰好留下规则需要的那 1 比特，其余全部丢掉。
- 4 个误差引导的吸引子在 f_xor 上与无监督的 16 个相当（0.619）。

### 从经验提取规则、在新场景按规则预测（`demo/rule-extraction.mjs`，图 9）

像 Minecraft 挖方块：每次经历 = 一个方块 + 一把工具 → 挖得快还是慢。规则是"工具对路就快"（锹挖土类、斧砍木类、镐敲石类）。
- 方块的可感知特征：颜色、亮度、纹理（外观）+ 敲击声（硬度的线索），各 12 个神经元群体编码。外观占输入的四分之三。
- 每种材质都有一个长得几乎一样的别种材质：泥土 ≈ 深色橡木，砂砾 ≈ 石头，白桦 ≈ 闪长岩。

网络：特征注意力 → 第一层 4 个吸引子（方块 → 概念，比 9 种方块少，必须合并）→ 第二层 12 个吸引子（概念 + 工具 → 情境）→ 读出（情境 → "快"的概率）。

每次经历分两个相位：
- 预测相位：只凭看到的东西自下而上沉降，给出预测。
- 结果相位（只在预测错了时）：实际结果钳住顶层，工具不变。第二层只允许"会给出实际结果"的情境，于是第一层只剩"配上这把工具会通向这类情境"的概念，在其中取最像看到的方块的那个。结果就这样逐层改写了下层的解释。
- 学习：重新解释后的概念向这次输入靠拢，原来的概念退开；注意力向"支持正确概念"的特征倾斜（同 ALCOVE，Kruschke 1992）。找不到一致的概念，说明规则本身要改，只调读出。

| | 注意力（颜色 / 亮度 / 纹理 / 声音） | 见过的方块 | 外观没见过的新方块 | 陷阱：见过的外观配另一种材质的声音 |
| --- | --- | --- | --- | --- |
| 结果逐层传回 | 0.06 / 0.08 / 0.08 / **3.78** | 98.3% | 98.1% | **98.5%**（18 种） |
| 只有前馈抽象（结果只调读出） | 1 / 1 / 1 / 1（不学） | 92.6% | 98.3% | 73.0% |
| 逐层传回，经验缺少变化，声音碰巧最好分 | 0.05 / 0.05 / 0.17 / 3.73 | 99.6% | 99.2% | 99.4%（6 种） |
| 逐层传回，经验缺少变化，外观和声音一样好分 | 0.07 / 1.26 / 1.42 / 1.24 | 88.9% | 76.9% | 56.1%（6 种） |

- **规则是怎么被提取出来的**：起初第一层按外观归类（砂砾和石头一类）。"砂砾 + 锹"预测慢、结果快，结果相位把它重新解释为"泥土、沙子"那一类；"闪长岩 + 锹"预测快、结果慢，被改写到别处。每次改写都让概念向材质靠一点、让注意力向声音移一点。最后第一层是 3 个按材质 100% 纯的概念，第二层是"概念 × 工具"的情境，读出就是规则表。
- **在新场景里按规则预测**：没见过的外观（红沙、绯红木、诡异木、深板岩）按声音归到对的材质；"灰色的木头""白色的软方块""褐色的硬方块"这类长得像别种材质的陷阱也按规则答对。只有前馈抽象的网络按外观归类，三个陷阱全错。
- **经验必须有变化**：每种材质只见过一种外观时，外观和声音同样完美地解释了全部经验，经验本身决定不了规则依赖哪个特征。声音碰巧最好分时网络学到了对的规则；外观一样好分时它把注意力分给了外观，陷阱只答对 56%。要把真正的原因分离出来，需要"同一种材质出现不同外观、不同材质出现相同外观"这样的对照。

### 结论

1. **适用，但近似是读出做的**：一层吸引子加一条三因素读出满足万能近似定理（径向基意义上），误差随吸引子数下降。无监督的吸引子学习只提供"基"，并不知道要近似什么。小脑、蘑菇体、纹状体正是这种结构。
2. **多层迭代激活不扩大能近似什么**：一层已经什么都能近似；无监督地往上叠，关于刺激的信息只能保持或丢失。
3. **它改变的是"什么变得容易读出"以及"什么被丢掉"**：
   - 组合：把经常一起出现的下层吸引子绑成上层吸引子（部件 → 整体），下层分开的特征之间的交互由此变得可读；
   - 补全与解释：上层吸引子把残缺的整体补全，把没见过的组合归到最近的已知整体；
   - 抽象：逐层粗粒化，越往上越只认类别、丢掉细节。同一层里侧向联系越学越强，也是同一种粗粒化。
4. **两个前提**：
   - 各层按强度分级传递：只传"谁赢了"会切断相似结构；
   - 世界本身是组合的：部件以不同搭配反复出现，否则上层没有可绑的共现结构。
5. **与深度学习的差别**：深度网络的中间层由反向传播按目标误差塑形，所以深度能带来效率优势：对层层组合的函数，浅层大约需要 ε^−d 个单元，按组合结构分层的深层只需大约 d·ε^−2 个（Poggio et al. 2017）。我们的中间层只按共现学习，这个优势只在中间吸引子恰好对应世界的部件时才出现。要让中间层也为目标服务，需要把误差信号送到中间层：多巴胺广播的三因素规则、反馈对齐、预测误差。

## 多层脉冲网络：前馈、有向通道、反馈接成回路

代码：`src/L4-network/layered-network.mjs`（多层网络）、`demo/lib-hierarchy.mjs`（世界与逐层训练）、`demo/fig10-hierarchy.mjs`（图 10）。验证：`verify/L4-hierarchy.mjs`。

### 结构

每一层都是第 4 层脉冲版那样的完整网络：100 个兴奋性 + 25 个抑制性 LIF 神经元，可塑的兴奋→兴奋突触（钙规则 + 异突触竞争），抑制性可塑性，背景输入。层与层之间全是突触：
- **前馈 ↑**：第 k 层兴奋 → 第 k+1 层兴奋，按组对应的拓扑投射（同组连接概率 0.5、异组 0.02），强度固定；另有到第 k+1 层抑制性神经元的前馈抑制。
- **反馈 ↓**：第 k+1 层兴奋 → 第 k 层兴奋，随机连接（概率 0.3），起点很弱，按钙规则学习。
- **上层的异突触预算 0.3**（第一层 0.2）：上层吸引子由下层两个吸引子合成（40 个神经元），预算 0.2 时组内连接几乎占满，物体级通道长不起来（X→Y 只有 0.09）。真实皮层沿层级往上，锥体神经元的树突棘也越来越多（Elston 等人的测量）。

### 世界与训练

- 基本项 A、B、C、D 是第一层的吸引子。物体 X = A + D、Y = C + B，物体内部有先后（A 之后 D、C 之后 B）。物体之间也有先后：X 之后是 Y。
- 物体这样配对的原因：这个随机种子的第一层在变体学习中偶然长出了 A→D（0.27）和 C→B（0.35）两条有向联系，原先安排的 A→B、C→D 通道却没长起来。把物体定义成与已有联系一致后，第一层跨物体的联系都只有 0.01–0.13，第一层自己预测不了另一个物体。
- 第一层从不经历 X→Y，所以第一层里出现的任何"Y"都只可能来自上层。
- 逐层训练：
  - 第一层：变体 150 次，长出吸引子；A→D、C→B 各 40 遍（每项 40 ms），长出物体内的有向通道。
  - 第 k 层：物体 100 次（两个部件同时出现），长出物体级吸引子并学习反馈；再经历物体序列 X → Y 120 遍（每个物体 40 ms），长出物体级有向通道。
  - 训练第 k 层时，下面各层的兴奋性突触冻结（网络的连接组新增 `frozen` 标记，未冻结的组逐拍结果与原来相同），抑制性可塑性保留。
  - 1–4 层网络都取自这同一套逐层训练。

### 学到的结构（4 层网络）

| 层 | 物体内绑定 | X→Y | Y→X | 反馈：同物体 / 跨物体 |
| --- | --- | --- | --- | --- |
| 1 | A→D 0.37、C→B 0.37（反向 0.13、0.12） | 0.05 | 0.05 | — |
| 2 | 0.48 | **0.23** | 0.06 | 0.32 / 0.01 |
| 3 | 0.47 | 0.07 | 0.11 | 0.27 / 0.03 |
| 4 | 0.44 | 0.07 | 0.16 | 0.25 / 0.03 |

这个网络以群体爆发工作：一次刺激引起十几毫秒的集体爆发，随后放电适应、突触压抑和抑制让整层沉默约 100 ms。学到的预测表现为：同一次爆发里，被预测的组紧接着被拉起，而不是在"该出现的时刻"才出现。

### 前馈、有向通道、反馈各自做了什么

测试时只给一个与训练时一样短（40 ms）的 X。"没经历序列"指上层只经历过物体、没经历过 X→Y。

| | 1 层 | 2 层 | 2 层，切断反馈 | 2 层，没经历序列 |
| --- | --- | --- | --- | --- |
| 第二层 Y 的组，比静息多（0–50 ms） | — | 2.5 Hz | 2.5 Hz | 0.1 Hz |
| 第一层 Y 的组放电 | 0.6 Hz | 0.8 Hz | 0.5 Hz | 0.8 Hz |
| 第一层 Y 的组膜电位（相对静息） | −12.8 mV | −13.4 mV | −13.4 mV | −13.4 mV |
| 第一层的不变性（同一物体两种不重叠的刺激） | 0.55 | 0.92 | 0.52 | 0.91 |
| 第一层的补全（只给 A 的一半，D 组比静息多） | 9.2 Hz | 11.9 Hz | 9.3 Hz | 11.6 Hz |
| 想象：只驱动第二层的 X，第一层 X 的组 | — | 16.3 Hz | 0 | 16.1 Hz |
| 想象：第一层 Y 的组膜电位最多升高 | — | 1.5 mV | 0.05 mV | 0.4 mV |

- **↑ 抽象**：第二层长出物体级吸引子。
- **→ 预测**：第二层长出有方向的物体级通道。只给 X 时第二层 Y 的组被提前拉起；没经历序列的第二层不会。
- **↓ 反馈**：上层把第一层补全成完整的物体。第一层的不变性从 0.55 升到 0.92，补全从 9.2 Hz 升到 11.9 Hz；切断反馈后都回到单层水平。第一层没有任何刺激时，只驱动上层（像想象或回忆）也能在第一层重建出 X。
- **没成立的一环：预测的 Y 传不到正在感知 X 的第一层。**
  - X 的爆发招募抑制性神经元，把第一层其余神经元压低约 13 mV，持续约 100 ms。上层传下来的那一次短暂爆发抵不过：完整网络比没经历序列的网络只高 0.05 mV。
  - 紧接 X 出现的 Y 在头 20 ms 也被完全压住（0 Hz；空白之后出现则是 49 Hz）。
  - 想象时第一层没被当前输入占据，预测能传下来一点（膜电位多 1.1 mV，Y 的组 1.2 对 0.7 Hz），但重建出的 X 一爆发，又把它压了下去。

### 层数

| | 1 层 | 2 层 | 3 层 | 4 层 |
| --- | --- | --- | --- | --- |
| 最上层的不变性 | 0.55 | 0.98 | 1.00 | 1.00 |
| 第一层的补全（D 组） | 9.2 Hz | 11.9 Hz | 12.1 Hz | 12.2 Hz |
| 残缺 + 噪声时最上层的辨识度（8 组噪声平均，`demo/noisy-depth.mjs`） | 0.65 | 0.38 | 0.40 | 0.48 |
| 250 ms 内整个网络的 ATP（×10⁹） | 701 | 1288 | 1850 | 2425 |

- 不变性与补全到 2–3 层就饱和；每加一层，能耗约多 580×10⁹ ATP（250 ms 内）。
- 第 3、4 层没学到正向的物体级通道，反而长出了反向联系：第二层已经在预测，传上来的不再是干净的"先 X 后 Y"。
- 上层并不比第一层更抗噪。上层做的是全或无的类别判断：同一个残缺的 X 加不同的噪声，有时判得全对（0.98），有时整个翻成 Y（−0.23），平均反而不如第一层的分级响应。（`demo/fig10-hierarchy.mjs` 每个网络只抽一组噪声，3 层那组恰好很坏，给出 0.04；不能据此说第 3 层学错了。）
- 这个世界只有两级结构，层数超过它，就只剩代价。

### 第一步：顶树突——反馈只做阈下调制（`demo/fig11-apical.mjs`，图 11）

兴奋性神经元加上顶树突分区（Larkum 1999；简化形式取自 Naud & Sprekeler 2018），反馈全部落在顶树突上，前馈与层内连接仍落在胞体：
- 顶树突有自己的膜电位与受体（NMDA 的镁阻断按树突电位算），越过约 −35 mV 就自我放大成持续二三十毫秒的钙平台，平台把电流送进胞体；胞体放电反传到树突，约抬高 15 mV。
- 树突没有输入时，神经元与点神经元完全相同（同一套第一层权重，两种神经元对 X 的放电逐分箱一样），没设顶树突的网络逐拍不变。
- 单个神经元：只有顶树突的中等输入时不放电、树突只抬高几毫伏；只有胞体输入时 16 Hz、没有爆发；两者同时到来时 19 Hz、一半的放电间隔落在爆发里——"预测与证据对上才放大"。顶树突输入过强时神经元靠平台自己爆发（像幻觉），所以反馈要适中。

两种结构用同样的方式逐层训练、同样测试：

| | 点神经元（反馈落在胞体） | 带顶树突（反馈落在顶树突） |
| --- | --- | --- |
| 第 3、4 层的物体级通道 X→Y / Y→X | 0.07 / 0.11、0.07 / 0.16（反了） | **0.24 / 0.04、0.21 / 0.07**（正向） |
| 第二层被预测的 Y 的组（2 层 / 没经历序列） | 2.5 / 0.1 Hz | 1.8 / 0.3 Hz |
| 第一层 Y 的组顶树突，X 出现后（2 层 / 没经历序列） | — | 峰值约高 3 / 1 mV，约 20 ms 后退回 |
| Y 紧跟 X：第一层 Y 的组首个脉冲延迟（2 层 / 没经历序列） | 33.0 / 33.3 ms | 31.1 / 31.1 ms |
| 第一层的不变性（2 层） | 0.92 | 0.55（与单层相同） |
| 想象：只驱动第二层的 X，第一层 X 的组 | 16.3 Hz | 10.9 Hz |

- **往上传的证据干净了**：反馈只做调制，不再把上层的猜测混进第一层的放电，再往上的层收到的是干净的"先 X 后 Y"，第 3、4 层第一次学到正向的物体级通道。
- **反馈不再"补全"下层**：没被刺激的成员只收到阈下的树突输入、不放电，第一层的不变性回到单层水平；强的自上而下输入（想象）仍能经树突平台驱动第一层。
- **预测仍然传不到正在感知的第一层**：顶树突只有一个约 20 ms 的小峰，等不到 Y 在 40 ms 时到来，Y 的响应没有任何提前。瓶颈在发送端：第二层自己的"Y 的预测"也在胞体里和当前的 X 竞争，只挤出零星几个脉冲，送下来的反馈太少。真实皮层里，预测由深层神经元以真实放电的形式送出，深层不参与浅层的竞争——这是下一步要加的。

### 第二步：深层神经元群——预测由深层发出（`demo/fig12-deep.mjs`，图 12）

每层分成两群：
- **浅层**（带顶树突）：负责吸引子竞争，把证据往上送。
- **深层**：膜时间常数 40 ms、放电适应弱、自身抑制弱，不参与浅层的竞争。浅层把当前状态以 NMDA 为主的突触拷贝给深层（浅层一次爆发，深层持续去极化几十毫秒），深层在这段保持里学"现在 → 接下来"的联系。
- 预测的去向：本层浅层的顶树突（按柱对应）、下一层浅层的顶树突、下一层深层（这两条按钙规则学）。
- 序列训练时只有深层学习：第二层若出现对 Y 的预测，只可能来自深层。

拷贝强度的选择（深层还没学习时，40 ms 的 X 接 40 ms 的 Y）：强度 10 时深层的 X 只放一阵、保持不住；20 时深层的 X 一直保持到深层的 Y 开始（约 75 ms），像交棒；40 时两边都持续很久，有失控的风险。取 20。把序列再压缩到每项 20 ms 不行：Y 落在 X 爆发之后的抑制窗里，浅层完全没有反应。

| 只给 A 的一半成员：第一层浅层 D 组（A 的物体伙伴）顶树突比静息高 | 1 层 | 2 层 | 2 层，没经历序列 | 2 层，切断深层反馈 |
| --- | --- | --- | --- | --- |
| | 2.0 mV | **8.6 mV** | 7.2 mV | 1.9 mV |

| 只给 40 ms 的 X | 2 层 | 2 层，没经历序列 | 2 层，切断深层反馈 |
| --- | --- | --- | --- |
| 第二层深层 X 的组 / Y 的组 | 16.4 / 0.2 Hz | 10.5 / 0 Hz | 16.4 / 0.2 Hz |
| 第一层浅层 Y 的组顶树突（10–120 ms 平均） | +0.19 mV | +0.05 mV | +0.02 mV |
| Y 紧跟 X：第一层首个脉冲延迟 | 31.2 ms | 31.5 ms | 31.5 ms |

- **深层通路能把预测送下来，不再被压住**：第二层认出物体 X，深层把它保持住，经反馈在第一层的顶树突上预先准备好"缺的那一半"（约 6.6 mV，切断深层反馈即消失，与是否经历过序列无关）。点神经元结构下这种反馈被抑制压住，只加顶树突时只有约 1 mV。第一层自己的深层也在工作：只给 A，第一层深层的 D 组 12.4 Hz。
- **对"下一个物体"的预测在源头没产生**：只给 X 时第二层深层的 Y 组几乎不动，第一层也就没有对 Y 的准备，Y 的响应没有提前。原因是深层的持续活动：X 与 Y 有一大段同时放电，两种先后都出现，学到的是没方向（第一层深层 A↔D 0.50 / 0.51）甚至反向（第二层深层 X→Y 约 0.15，Y→X 约 0.25）的联系——持续活动学出"组块"，短暂活动才学出"序列"；而深层的 X 持续放电时，又经深层自己的抑制压着 Y。
- 要让深层同时有持续（跨过 X 与 Y 之间的空档）和方向（只从 X 指向 Y），还缺一个在时间上把"当前"与"接下来"排开的机制：深层的 X 在 Y 开始时干净地交出去（更强的适应、或与节律相位绑定的交棒），或者一个两侧不对称、增强一侧更宽的学习窗。

### 要让预测真正传到下层，还缺的结构（真实皮层都有）

1. **不止一池全局抑制**。现在当前输入赢了竞争，就把包括"被预测者"在内的所有神经元一起压下。皮层有多种中间神经元，自上而下的信号可以经 VIP 中间神经元去抑制，为被预测的神经元开门（Pi et al. 2013；Zhang et al. 2014）。
2. **预测与证据分在不同的神经元**。皮层浅层锥体细胞主要承载自下而上的输入，深层承载输出与预测。反馈主要落在顶树突上，做阈下调制，与自下而上的输入同时到来时才触发放电。我们的点神经元没有树突分区，预测只能和当前输入在同一群神经元里抢放电。
3. **预测要在"该出现的时刻"出现**。现在的预测被压缩进同一次爆发里；真实大脑用节律相位（θ、α）把"当前"和"接下来"排在一个周期的不同时段。
4. **上层要学自己时间尺度上的转移**，而不是下层已经压缩过的预测。

## 第 5 层：脑结构

### 方向环（果蝇中央复合体）

`src/L5-brain/head-direction.mjs`，连接核来自 `data/malecns-epg-kernel.json`。它是 maleCNS v1.0 里实测的 EPG→EPG 有效作用：直接连接，加上经 PEN、PEG、Δ7 的两步通路，按相位差分 8 档。

- **对称部分**（直接 + Δ7 的偶部）：近处支持、对面抑制的井。撤掉地标后，凸包 200τ 内只漂移 0.1°，是连续吸引子。
- **实测的左右不对称**（奇部，±45° 处 −0.045，对比偶部 0.91）：带上它，凸包在黑暗中 200τ 漂移 57°。实测接线的左右差像一股恒定的风，真实果蝇需要视觉地标不断重校准。
- **PEN 左右两路**被角速度调制：转速与角速度成正比（斜率 2.37 °/τ）。路径积分累计转过 134°，误差 0.7°；看到地标后，偏差在 0.2° 以内。
- **PFL3 转向读出**：朝向目标时为零且稳定，背对目标时为零但不稳定。
- 维持一个航向凸包：1.8×10¹¹ ATP/s，全静默为 1.6×10¹⁰。

### 前额叶工作记忆

`src/L5-brain/prefrontal.mjs`：每个槽位是一组互相抑制、各自自激的条目群体（吸引子）；门控信号（多巴胺 / 基底节式）决定外部输入能否进入。

- 门开时载入条目，门关时靠吸引子维持；
- 门关时干扰进不来，门开时才能更新；
- 槽位之间互相独立；
- 记住一个条目要付持续代价：2.4×10¹⁰ ATP/s，空闲时为 9.2×10⁹。

### 皮层规则学习（R2/R3 的生物对应）

`src/L5-brain/cortex.mjs`：预测误差驱动的三因素规则 Δw = α·δ·x（δ = 实际 − 预测，多巴胺式；x = 突触前活动，资格）。

- **差分（效应臂 vs 对照臂）**：B 总伴随 A 出现，但单独出现时没有结果——学到 w_A = 1.00、w_B ≈ 0。单纯的共现统计会给 B 0.51。
- **阻断**：结果已被旧线索预测，新线索学不到（0.00，对照组 0.50）。
- **合取规则**："状态 s₁ 且动作 a₁ 才有结果"线性学不准（−0.26 / 0.25 / 0.25 / 0.76）；经稀疏随机扩张（蕈状体 / 齿状回式）后，同一规则学成 0 / 0 / 0 / 1。
- **互补学习系统**：只学新任务会冲掉旧规则（旧任务误差 0.037）；海马把旧经历交错回放给皮层，新旧都保住（误差 < 10⁻⁸）。

## 已知缺口

1. **低频持续活动**：最简单的兴奋/抑制脉冲集合只有约 100 Hz 的持续态；皮层式的 10–50 Hz 持续活动需要 NMDA 饱和或短时程易化等机制。
2. **原样 maleCNS 接线跑不出环吸引子**：方向环用的是实测核的偶部加左右镜像的 PEN；按神经元级突触数直接模拟时，缺每对细胞类型的单位突触强度与细胞内在参数（见 `mc-agent/research/malecns/REPORT-data.md` 第 3 节）。
3. **第 4 层速率版与第 5 层是粗粒化的**：一个单元代表一个神经元的放电率（L5 的海马用 k 个赢者代替篮状细胞），每单元的 ATP 由 L1/L2 的常数换算。第 4 层的脉冲版（L4b）是逐个脉冲、逐个突触算的，但只有 100 个兴奋性神经元，吸引子较浅。
4. **学习加速**：第 3 层群体实验把钙规则的时间常数缩短了 5 倍（150 s → 30 s）。更大的加速会破坏"慢变量"假设——每个放电周期内 ρ 就会跑到阶段性平衡点。
5. **还没有的结构**：基底节（动作选择）、蕈状体的多巴胺分区、神经调质的状态（觉醒、饥饿）、胶质细胞，以及把五个模块接成一个完整回路去完成任务（例如 L3 式"记住地点、走回去、拿起来"）。
6. **多层的中间层没有教学信号**：上层只会把一起出现的部件绑在一起，不会为某个目标去提取特征。把误差送到中间层的机制（三因素广播、反馈对齐、预测误差）还没有做。图 8 的两层实验里，层间的"绘图"由程序完成（读出激活度、换算成速率）；多层脉冲网络（图 10）里层间已是真实突触，但前馈是固定的拓扑投射，不学习。
7. **多层脉冲网络里，上层的预测传不到正在感知的下层**：每层只有一池全局抑制，当前输入的爆发会把被预测的神经元一起压下。加上顶树突（反馈只做阈下调制）后，往上传的证据变干净、第 3、4 层学到了正向的物体级通道，但预测仍下不来——上层自己的预测也在和当前输入竞争。再加上承载预测的深层神经元群后，物体层面的预测（缺的那一半）能经深层送到下层的顶树突（约 6.6 mV），但对下一个物体的预测在上层深层里就没产生——深层的持续活动学出的是没方向甚至反向的联系。还缺在时间上把"当前"与"接下来"排开的机制、多种中间神经元（去抑制）、节律相位（见"多层脉冲网络"一节）。
