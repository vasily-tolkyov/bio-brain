# bio-brain：逐层生物脑模型

从单个神经元一路搭到脑结构，共五层：

1. 单个神经元
2. 突触连接
3. 赫布学习
4. 网络里的吸引子与有向通道
5. 由多个网络组成的脑结构（方向环、海马、前额叶、皮层规则）

每一层都有一个验证脚本，用数字证明这一层具备该有的性质；下一层只用上一层已验证过的东西。

每一层同时记两本能量账：

| 账 | 是什么 | 最低点在哪 |
| --- | --- | --- |
| **代谢账（ATP）** | 真实耗掉的能量：维持静息、动作电位、突触传递（钠钾泵、钙泵、Cl⁻ 外排） | 全体静默 |
| **动力学账（能量函数）** | 网络"要维持这个状态需要多少外力"；对称连接时它沿动力学只降不升 | 吸引子 |

两者的关系是本项目要讲清楚的事。

- 吸引子不是代谢最低点。
- 但排除"全体静默"这个平凡解后，确实存在"能完成任务的最省能吸引子"（第 4 层）。
- 赫布学习让"一起激活"变省，省的是上游驱动，不是单次传递（第 3 层）。

运行：

```bash
npm run verify          # 全部五层，约 100 秒
node verify/L1-neuron.mjs   # 单独某一层（L1 … L5）
```

零依赖，Node ≥ 20。

## 第 1 层：单个神经元

`src/L1-neuron/hh.mjs`：标准 Hodgkin–Huxley（乌贼参数，T 按 Q10 = 3 缩放门控速率）。

漏电拆成 Na⁺ 漏和 K⁺ 漏两部分，使合并后的反转电位等于 E_L。这样静息时虽然净电流为零，Na⁺ 仍在不断漏进来，钠钾泵要持续付费，这就是静息成本。

\[
\text{ATP} = \frac{\int I_{Na}^{\text{内流}}\,dt}{e} \times \frac{1}{3}
\]

`calibrateHH` 给出：
- 静息成本（ATP/ms/cm²）；
- 一次动作电位的成本（只在放电本身里积分，扣掉同时段的静息漏）；
- 重叠系数（Na⁺ 内流 / 把膜电容充到峰值所需的最少电荷 C·ΔV）。

重叠系数大，是因为 Na⁺ 内流与 K⁺ 外流在时间上重叠，互相抵消；温度升高时通道变快、重叠变少，所以更省能。

`src/L1-neuron/lif.mjs`：点神经元（200 pF、10 nS，即 20000 µm²、膜电阻 20 kΩ·cm²），带适应电流 w。`mammalianCosts` 按哺乳动物式的重叠系数 1.3 缩放放电成本，按漏电导缩放静息成本，得到：
- 每次放电约 5.7×10⁷ ATP；
- 静息约 5.1×10⁸ ATP/s（Attwell & Laughlin 2001 估算大鼠神经元维持静息约 3.4×10⁸ ATP/s，同一量级）。

## 第 2 层：突触

`src/L2-synapse/synapse.mjs`：一个连接 = `contacts` 个释放位点，每个以 p·R 的概率释放一个囊泡（R = 可用囊泡比例，被短时程压抑消耗、按 τ_rec 恢复）。

- 电流：I = Σ g(t)·B(V)·(E − V)。
- 镁阻断：B(V) = 1/(1 + [Mg]/3.57·e^{−0.062V})。正是它让 NMDA 成为"突触前有递质"且"突触后已去极化"的同时检测器。
- 突触前成本：按囊泡计（递质回收、囊泡循环、Ca²⁺ 外排）。
- 突触后成本：按真实流过受体的离子计（Na⁺ 1/3 ATP、Ca²⁺ 1 ATP、Cl⁻ 1/2 ATP）。

突触越强，单次传递越贵——这在第 3 层会变得重要。

## 第 3 层：赫布学习

`src/L3-plasticity/calcium-rule.mjs`：

\[
\tau\frac{d\rho}{dt} = -\rho(1-\rho)(\rho^*-\rho) + \gamma_p(1-\rho)[c>\theta_p] - \gamma_d\,\rho\,[c>\theta_d]
\]

- 钙 c 有两个来源：突触前脉冲经 NMDA 进来（延迟 D），突触后放电反传到树突、经电压门控钙通道进来。
- "前在后前"时两份钙叠加越过高阈值 → 增强；"后在前前"时只越过低阈值 → 减弱。
- 效能 ρ 映射到第 2 层突触的量子电导缩放。
- `eta > 0` 时加入 NMDA 同时检测：突触后放电时，已结合递质的 NMDA 受体被挪开镁塞，多进一份钙。

`src/L3-plasticity/circuit.mjs`：把第 1–3 层拼成脉冲回路。泊松上游驱动的放电与突触成本记到 `drive` 类别。

**"一起激活更省"的实验**（`verify/L3-hebbian.mjs`）：

1. 10 个两两互连的神经元先被爆发式地一起激活 15 s，突触从 ρ = 0.05 增强到 0.59（强度 ×8）。
2. 冻结可塑性后，用二分法找出"让这群神经元平均放到 10 Hz"所需的最少上游驱动：学习前每条输入 41.3 Hz，学习后 29.8 Hz。
3. 整个系统（含上游）的 ATP 从 7.17×10¹¹ 降到 5.20×10¹¹ ATP/s（−27%）。但群体自身的开销略升（1.10×10¹⁰ → 1.18×10¹⁰），因为每个囊泡的突触后成本从 5.3×10⁴ 升到 4.3×10⁵ ATP。

结论：赫布学习省下的是"外部需要推多少"，不是单次传递的成本。

## 第 4 层：网络里的吸引子与有向通道

`src/L4-network/rate-network.mjs`：

\[
\tau\dot r = -r + g(Wr + b + I - a),\quad \tau_a\dot a = -a + k_a r
\]

\[
E(r) = -\tfrac12 r^\top W_s r - (b+I-a)^\top r + \tfrac1\beta\sum[r\ln r + (1-r)\ln(1-r)]
\]

- 对称部分 W_s 定义能量地形：W 对称、a 固定时 dE/dt ≤ 0，极小值就是吸引子。
- 反对称部分 W_a 不能写进任何能量函数，它是让状态沿固定方向流动的"风"。
- 疲劳 a 把当前的井慢慢填浅。

`src/L4-network/learning.mjs`：第 3 层钙规则在群体层面的平均效果。

| 规则 | 来自第 3 层的什么 | 作用 |
| --- | --- | --- |
| 协方差规则（对称） | 一起高频激活 → 双向增强 | 形成吸引子 |
| 时间不对称项 λ·ξ^{μ+1}ξ^{μ⊤} | 先后激活 → 单向增强 | 形成有向通道 |
| 突触有上限的版本 | 单个突触强度有限 | 小集合撑不起来 |

`src/L4-network/metabolism.mjs`：速率状态的 ATP = N × 静息 + Σ 放电率 × (单次放电 + 输出突触)，常数来自第 1、2 层。

验证结果见总览表。其中两条直接回答"排除静默后有没有能耗极小"：
- 吸引子状态（4.0×10¹¹ ATP/s）比静默（1.0×10¹¹）贵，所以吸引子不是代谢最低点；
- 但在突触强度有上限时，只有每个模式 20 个神经元（f = 0.1）的编码能完成补全：更稀疏的撑不起自己，更密的互相干扰。能工作的最省能吸引子就落在这里。

脉冲层面：40 个兴奋 + 10 个抑制的 LIF 集合是双稳态的，短暂刺激后自持放电（约 100 Hz），短暂抑制后回到静默；持续态的 ATP 约是静默的 20 倍。

## 第 5 层：脑结构

### 方向环（果蝇中央复合体）

`src/L5-brain/head-direction.mjs`，连接核来自 `data/malecns-epg-kernel.json`。它是 maleCNS v1.0 里实测的 EPG→EPG 有效作用：直接连接，加上经 PEN、PEG、Δ7 的两步通路，按相位差分 8 档。

- **对称部分**（直接 + Δ7 的偶部）：近处支持、对面抑制的井。撤掉地标后，凸包 200τ 内只漂移 0.1°，是连续吸引子。
- **实测的左右不对称**（奇部，±45° 处 −0.045，对比偶部 0.91）：带上它，凸包在黑暗中 200τ 漂移 57°。实测接线的左右差像一股恒定的风，真实果蝇需要视觉地标不断重校准。
- **PEN 左右两路**被角速度调制：转速与角速度成正比（斜率 2.37 °/τ）。路径积分累计转过 134°，误差 0.7°；看到地标后，偏差在 0.2° 以内。
- **PFL3 转向读出**：朝向目标时为零且稳定，背对目标时为零但不稳定。
- 维持一个航向凸包：1.8×10¹¹ ATP/s，全静默为 1.6×10¹⁰。

### 海马

`src/L5-brain/hippocampus.mjs`，用 k 个赢者代表篮状细胞的强反馈抑制。

| 区 | 做什么 | 实测 |
| --- | --- | --- |
| DG | 随机稀疏投射 + 2% 赢者 → 模式分离 | 80% 重叠的输入 → DG 重叠 0.35 |
| CA3 | 苔藓纤维引爆、一次性赫布学习的回返连接 → 补全 | 每条经历见一次就存下，半个线索补全到 1.00 |
| CA1 | 比较"CA3 提取出的预测"与"EC 直接给的码" → 新奇 | 熟悉 0.00，新输入 ≥ 0.75 |
| 重放 | 编码时的不对称连接（前一项 → 后一项）+ 疲劳 | 按经历顺序 0→1→…→5；去掉不对称不动，去掉疲劳走一步就卡住 |

### 前额叶工作记忆

`src/L5-brain/prefrontal.mjs`：每个槽位是一组互相抑制、各自自激的条目群体（吸引子）；门控信号（多巴胺 / 基底节式）决定外部输入能否进入。

- 门开时载入条目，门关时靠吸引子维持；
- 门关时干扰进不来，门开时才能更新；
- 槽位之间互相独立；
- 记住一个条目要付持续代价：2.4×10¹⁰ ATP/s，空闲时为 9.2×10⁹。

### 皮层规则学习（R2/R3 的生物对应）

`src/L5-brain/cortex.mjs`：预测误差驱动的三因素规则 Δw = α·δ·x（δ = 实际 − 预测，多巴胺式；x = 突触前活动，资格）。

- **差分（效应臂 vs 对照臂）**：B 总伴随 A 出现，但单独出现时没有结果——学到 w_A = 1.00、w_B ≈ 0。单纯的共现统计会给 B 0.51。
- **阻断**：结果已被旧线索预测，新线索学不到（0.00，对照组 0.50）。
- **合取规则**："状态 s₁ 且动作 a₁ 才有结果"线性学不准（−0.26 / 0.25 / 0.25 / 0.76）；经稀疏随机扩张（蕈状体 / 齿状回式）后，同一规则学成 0 / 0 / 0 / 1。
- **互补学习系统**：只学新任务会冲掉旧规则（旧任务误差 0.037）；海马把旧经历交错回放给皮层，新旧都保住（误差 < 10⁻⁸）。

## 层与层之间怎么接

| 从 | 到 | 用的是什么 |
| --- | --- | --- |
| L1 | L2–L5 | HH 标定出单次放电和静息的 ATP，点神经元继承这些成本 |
| L2 | L3–L5 | 突触后每囊泡成本由真实受体电流算出，L4 的代谢账直接引用 |
| L3 | L4 | 钙规则在群体层面平均成两条规则：协方差规则（一起高频激活 → 双向增强）、时间不对称规则（先后激活 → 单向增强） |
| L4 | L5 | 方向环、CA3、前额叶槽位都是"对称的井"；序列重放与方向环转动都是"反对称通道 + 疲劳 / 调制"；DG 与皮层扩张是 L4 讲的稀疏编码 |

## 已知缺口

1. **低频持续活动**：最简单的兴奋/抑制脉冲集合只有约 100 Hz 的持续态；皮层式的 10–50 Hz 持续活动需要 NMDA 饱和或短时程易化等机制。
2. **原样 maleCNS 接线跑不出环吸引子**：方向环用的是实测核的偶部加左右镜像的 PEN；按神经元级突触数直接模拟时，缺每对细胞类型的单位突触强度与细胞内在参数（见 `mc-agent/research/malecns/REPORT-data.md` 第 3 节）。
3. **第 4、5 层是粗粒化的**：一个单元代表一个神经元的放电率（L5 的海马用 k 个赢者代替篮状细胞），每单元的 ATP 由 L1/L2 的常数换算，没有逐个脉冲地算。
4. **学习加速**：第 3 层群体实验把钙规则的时间常数缩短了 5 倍（150 s → 30 s）。更大的加速会破坏"慢变量"假设——每个放电周期内 ρ 就会跑到阶段性平衡点。
5. **还没有的结构**：基底节（动作选择）、蕈状体的多巴胺分区、神经调质的状态（觉醒、饥饿）、胶质细胞，以及把五个模块接成一个完整回路去完成任务（例如 L3 式"记住地点、走回去、拿起来"）。
